What you can delegate

Give it the outcome you need.

Investigate and repair

“Find why this request is slow, and fix the cause.”

The Bot reads the project, narrows the scope and delegates bounded changes with explicit verification criteria.

Bring back: root cause, diff and checks actually performed.

Move an engineering change

“Update this feature across the project. Keep the API compatible.”

Independent write tasks isolate in worktrees. Quote a message anytime to add context or steer a specific task.

Bring back: scoped diffs, verifier verdict and open gaps.

Research and document

“Compare these approaches and write down a recommendation.”

Keep sources, notes and deliverables attached to the project. Read documents and code right beside the thread.

Bring back: structured conclusion, references and open questions.

Local authority & contract chain

Your machine keeps the authority.

Every capability—Bash, files, search, MCP, Skills or Plugins—must pass the exact same six-stage local contract. There are no hidden side doors.

01 Capability Provider Local files, shell, MCP, skills, plugins
02 Manifest Declared scope & risk metadata
03 Runtime Projection Mode-gated visibility (bot stays read-only)
04 Tool Call Scoped to bound GoalPlan & worktree
05 PermissionGrant Host-verified user or policy grant
06 Evidence Command stdout, exit code, diff & verdict

What stays on your machine

Desktop, TUI and CLI share the same ~/.peer-agent state and OS keychain vault. Model text can never mint a permission or fake completion.

  • Operations stay within the project grant; the project Bot cannot approve permissions for you.
  • A finished reply is not proof of done. Runtime verification gates evaluate actual Evidence.
  • Interrupted or withdrawn tasks preserve history and reconcile unknown outcomes before any replay.

What goes to model cognition

Cognition may run via cloud APIs, OAuth subscriptions, Coding Plans or local endpoints. Local-first means local control, not pretending cloud models receive nothing.

  • System Context assembles only admitted prompt sources—tool outputs never become system instructions.
  • Attachment, image and context admissions respect per-project scope and explicit user consent.
  • Credentials live in the native Secret Service / Keychain via Rust peer-credential-helper.
