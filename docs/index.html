Designed around task flow.

Fully open source (MIT). Not another chat shell — work moves through tasks: handoff, continuity, and follow-up, closed with Evidence.

⇄

Task handoff

Goals are accepted with boundaries, clarified, planned (L0–L3), executed, and closed against success criteria.

⇉

Continuity

Persistent Goal state with pause, resume, and waiting-for-you — tasks survive sessions and interruptions.

?

Follow-up, not guessing

On critical ambiguity, risky trade-offs, or missing permissions, it asks with clickable options — never guesses.

⌘

Multi-channel access

Desktop, TUI/CLI, Quick Chat, Automation, and MCP — one machine, one config, one permission chain.

◎

Rich pluggability

MCP servers, plugin & skill marketplace, and declarative capability manifests — all through one governed pipeline.

✦

Dispatch & acceptance

Dispatch needs your consent; results walk an explicit state chain, pass a self-check, then wait for your acceptance.
