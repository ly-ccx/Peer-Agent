## Delivered Client Surface

- Protocol contracts for Chat, Execution, Share, Memory, Billing, Channel, Governance, Observability, Statistics, Studio, Runtime Projection, client tool calls, PermissionGrant, and Evidence.
- Chat Kernel reducers and stream parsing for messages, Thinking, Tool timeline, confirmation gates, and message actions.
- Electron main Cloud Chat Gateway as the renderer-to-cloud boundary; renderer does not hold BUC tokens.
- Codex-style desktop chat surface for real cloud conversations, streaming composer, message actions, Thinking / Tool / Confirmation UI, context panels, inspectors, and lazy-loaded control-plane panels.
- Share, Working Memory, Memory Wiki, Billing, Channel filters, Channel Evidence, Statistics, Observability, Governance, Agent Studio, and Agent Memory review surfaces.
- Local Capability Proxy flow: Runtime Projection publish, client-initiated polling, local permission review, Rust CU Proxy health adapter, local result Evidence, denied/failed Evidence, and Evidence return retry.
- High-risk OpenClaw and Agent Memory write surfaces are visible as blocked gate matrices, not executable buttons.
