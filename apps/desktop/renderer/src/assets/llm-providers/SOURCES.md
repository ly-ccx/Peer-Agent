## Neutral fallback

OpenAI Compatible, Anthropic Compatible, and unknown/custom providers do **not** use any vendor logo. They keep a neutral system fallback drawn by Peer Agent so the UI does not imply a brand affiliation.

## Usage note

Brand marks remain the property of their respective owners. They are used only to identify the corresponding provider in the model configuration UI.
