## 说明

- **Peer Agent 0.0.4-beta.2** 聚焦任务工作台的信息组织、已读状态与中断恢复，让多工作区协作更清晰、更稳定。
- 会话搜索、任务卡片和侧边栏状态经过统一整理，减少重复信息和刷新闪烁。

## 新功能

- **项目讨论未读状态**：任务工作台可识别并展示项目讨论的未读状态，帮助快速定位新的协作内容。
- **按工作区组织搜索结果**：会话搜索结果按工作区分组，更容易在多个项目之间查找目标会话。

## 优化

- **任务已读体验**：任务总览会持久保存已读状态，并简化标记已读的交互控件。
- **工作台布局**：统一运行中、中断和其他任务卡片的视觉层级，限制单张进展卡宽度，并移除重复进度摘要。
- **状态稳定性**：减少工作台刷新闪烁，保持草稿工作区选择，并在恢复会话时保留推理强度设置。
- **界面精简**：优化搜索控件和忙碌状态提示，隐藏暂不可用的调色板设置。

## 修复

- 修复中断后的 Goal 状态无法被准确保留和归类的问题。
- 修复打包版 Desktop 可能启动多个实例的问题。
- 修复会话已读状态与任务工作台已读状态容易混淆的问题。

## CLI（仅命令行）

- 本版 GitHub Release 附带 CLI 归档（与 Desktop 同 tag / 同版本）。
- 可通过 `npm i -g @peer-agent/cli@beta`（或 `pnpm add -g @peer-agent/cli@beta`）安装 beta 通道版本；`postinstall` 会拉取本版归档。
- 也可手动解压归档，将目录加入 `PATH`，执行 `peer --version` 校验后运行 `peer`。
- CLI 与 Desktop 继续共享 `~/.peer-agent` 下的会话和设置。

## Overview

- **Peer Agent 0.0.4-beta.2** focuses on task-workbench organization, read state, and interrupted-run recovery for clearer and more reliable multi-workspace collaboration.
- Conversation search, task cards, and sidebar status surfaces are now more consistent, with less duplicate information and refresh flicker.

## What's New

- **Unread project discussions**: the task workbench can identify and surface unread project discussions, making new collaboration activity easier to find.
- **Workspace-grouped search**: conversation search results are grouped by workspace for faster navigation across projects.

## Improvements

- **Task read-state workflow**: task-overview read state is persisted, with simpler controls for marking items as read.
- **Workbench layout**: running, interrupted, and other task cards now use a clearer visual hierarchy; advancing cards are width-capped and duplicate progress summaries are removed.
- **Stable state restoration**: workbench refresh flicker is reduced, draft workspace selection is preserved, and restored conversations retain their reasoning-effort setting.
- **Cleaner interface**: search controls and busy composer messaging are refined, while unavailable palette settings are hidden.

## Fixes

- Fix interrupted Goal state not being preserved and grouped accurately.
- Fix packaged Desktop builds allowing duplicate application instances.
- Fix conversation read state being confused with task-workbench read state.

## CLI (command-line only)

- This GitHub Release ships CLI archives under the same tag and version as Desktop.
- Install the beta channel with `npm i -g @peer-agent/cli@beta` (or `pnpm add -g @peer-agent/cli@beta`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
