## 说明

- **Peer Agent 0.0.5-beta.3** 跟进工作台抽屉和 Goal 验收：会话 / 结果抽屉恢复左侧圆角，验收完成后的卡片会进历史，打开历史不再卡死。

- 会话 / 结果抽屉恢复左侧圆角，最大化时不再被裁成直角。

- 跳转到某条消息后再发送，不再重放这次跳转，避免画面滚回去并闪回旧目标。

## Overview

- **Peer Agent 0.0.5-beta.3** follows up the workbench drawer and Goal acceptance: session / result drawers keep their left-side rounded corners, and accepted cards move into history without freezing the drawer.
- After jumping to a message, sending no longer scrolls back and flashes the old target.
- The docs changelog is in sync with this release.

## Fixes

- Restore the left-side rounded corners on the session / result drawer so maximize no longer clips them into a square.
- Send accepted completed cards into history; opening history no longer freezes the drawer.
- After a successful jump to a message, keep that one-shot navigation from replaying on send so the view does not scroll back and flash the old target.

## CLI (command-line only)

- This GitHub Release ships CLI archives under the same tag and version as Desktop.
- Install the beta channel with `npm i -g @peer-agent/cli@beta` (or `pnpm add -g @peer-agent/cli@beta`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
