## 新功能

- **置顶会话**：支持将重要会话固定在侧边栏顶部，切换和回访常用对话更方便。
- **文件拖拽上传体验**：聊天区新增文件拖拽覆盖层，拖入文件时有更明确的投放反馈。
- **Goal 模式审批联动**：打通 Goal 模式聊天审批与右侧面板联动，任务确认流程更连贯。

## 优化

- 优化桌面端运行时与侧边栏状态处理，提升会话列表、置顶状态和窗口交互的一致性。
- 会话列表会同步显示上下文压缩中的状态，长会话处理过程更清晰。
- Thinking 折叠头部调整为流动微光条样式，思考过程展示更轻量。
- 简化 MCP 连接配置流程，降低首次接入和维护成本。

## 修复

- 修复切换会话后工具调用进度可能残留的问题。
- 修复切换会话后历史流式错误状态可能残留的问题。
- 修复历史压缩后部分会话记录未正确保留的问题。
- 修复置顶会话、侧边栏分隔线和下拉菜单浮层的若干显示细节问题。

## What's New

- **Pin sessions**: keep important chats at the top of the sidebar for faster revisit.
- **File drag-and-drop UX**: chat area shows a drop overlay with clearer feedback when dragging files in.
- **Goal mode approval linkage**: chat approval cards sync with the right panel for a smoother confirm flow.

## Improvements

- Desktop runtime and sidebar state handling are more consistent for session list, pin state, and window interactions.
- Session list shows in-progress context compaction status for long chats.
- Thinking collapse header uses a flowing shimmer bar for a lighter look.
- Simplified MCP connection setup for first-time and ongoing maintenance.

## Fixes

- Fixed tool-call progress lingering after switching sessions.
- Fixed historical stream error state lingering after switching sessions.
- Fixed some session records not retained correctly after history compaction.
- Fixed display details for pinned sessions, sidebar dividers, and dropdown overlays.
