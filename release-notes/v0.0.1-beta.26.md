## 新功能

- **Goal 模式先判别再建目标**：Goal 模式下你的第一条消息不再被直接当成目标，而是先进入判别阶段——纯问答会静默还原为普通聊天，目标含糊会主动向你追问澄清，目标明确才正式建立并开始自驱执行，避免“发什么都建目标”。
- **新增 qoder CLI 供应商**：模型供应商支持接入 qoder CLI，通过本地 CLI 鉴权，不在应用内保存远端密钥。
- **模型列表改为分组手风琴**：LLM 设置里的模型按分组折叠展示，同组共享凭证、各模型独立参数；模型抽屉与图标统一优化，交互更清爽。

## 修复

- 修复切换会话时聊天滚动位置丢失，现在每个会话各自记住滚动位置。
- 修复给某个分组「加模型」时，重复显示已从分组继承的供应商级字段（渠道/鉴权/BaseURL/APIKey 等）。
- 修正 ChatGPT 订阅模式下的上下文窗口对齐。
- 修复流式重连时正文重复显示的问题。
- 修复流式重连时工具调用片段重复的问题。
- 修复会话列表刷新期间闪现“暂无会话”空窗，并防止慢请求晚返回覆盖新视图。

## What's New

- **Goal entry is more deliberate**: Ambiguous goals ask you for clarification first; only clear goals create a formal plan and start self-driven execution—avoids “everything becomes a goal”.
- **Added qoder CLI provider**: Model providers can use qoder CLI with local CLI auth; remote keys are not stored in the app.
- **Model list as grouped accordion**: LLM settings group models with shared credentials and per-model params; model drawer and icons are cleaner.

## Fixes

- Session scroll position is remembered per session when switching chats.
- “Add model” in a group no longer re-shows provider-level fields already inherited (channel / auth / BaseURL / API key).
- Aligned context-window sizing for ChatGPT subscription mode.
- Fixed body text duplication on stream reconnect.
- Fixed tool-call fragment duplication on stream reconnect.
- Fixed a flash of “no sessions” while the list refreshes, and slow late responses no longer overwrite the newer view.
