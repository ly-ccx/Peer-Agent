## 说明

- **Peer Agent 0.0.3** 是任务流 Agent 的稳定性与交互完善版本，聚焦签收、追问、执行、验收和恢复这条主链路。
- 本版继续坚持模型负责认知、本地负责能力、界面负责表达、契约负责边界、Evidence 负责治理。

## 主要变化

### Agent 任务流

- 完善任务签收与待确认状态，避免中断后的 intake contract 被误判为已完成。
- 增加结构化追问选项与治理后的 intake interaction 记录，让缺失决策可恢复、可追踪。
- 将 fast mode 明确为优先级层级，并恢复草稿场景下的快速执行体验。
- 完善目标结果抽屉、恢复流程和侧边栏模型选择持久化。

### Workbench 与交互

- 增加工作台线程结果查看、回退能力和完整的应用结果交互。
- 改进 sticky header、按钮状态、空状态与主题 token，减少长任务中的视觉抖动和状态歧义。
- 保持当前输入与线程状态之间的边界，降低恢复或切换任务时的误操作风险。

### 发布与文档

- 正式版标签要求提交已进入 `main`，避免从未合入主线的提交发布稳定版本。
- changelog 按稳定版与预发布通道拆分，并由 release notes 统一生成。
- 更新 README 中的 Provider 自由与安全说明。

## 升级建议

- 桌面版用户可直接安装本 Release 对应平台产物。
- CLI 用户可升级到 `@peer-agent/cli@0.0.3`。
- 升级不会清理现有 `~/.peer-agent` 会话、Provider 配置或凭据。

## Overview

- **Peer Agent 0.0.3** improves the reliability and interaction quality of the task-oriented Agent flow, with emphasis on intake, clarification, execution, acceptance, and recovery.
- The release continues to separate model cognition, local capabilities, UI presentation, protocol boundaries, and Evidence governance.

## Highlights

### Agent workflow

- Improve task intake and pending-confirmation handling so interrupted intake contracts are not mistaken for completed work.
- Add structured clarification choices and governed intake-interaction records, making missing decisions recoverable and traceable.
- Encode fast mode as a priority tier and restore fast execution for draft flows.
- Improve goal result drawers, recovery flows, and persistence of sidebar model selections.

### Workbench and interaction

- Add workbench thread-result viewing, rollback support, and complete apply-result interactions.
- Refine sticky headers, button states, empty states, and theme tokens to reduce visual jumps and ambiguous states during long-running tasks.
- Preserve the boundary between current input and thread state to reduce accidental actions while restoring or switching tasks.

### Release and documentation

- Require stable release tags to reference commits already merged into `main`.
- Split changelog output into stable and prerelease channels, generated from release-note sources.
- Update the README guidance for provider freedom and security.

## Upgrade

- Desktop users can install the platform asset attached to this Release.
- CLI users can upgrade to `@peer-agent/cli@0.0.3`.
- Upgrading does not remove existing sessions, Provider settings, or credentials under `~/.peer-agent`.
