## 说明

- **Peer Agent 0.0.9** 把隔离任务合回做成工作台分诊：干净改动自动合，过期分支可重建，真冲突才要你处理。
- Desktop Skills 可直接查询腾讯 SkillHub，并新增 Qoder 技能市场，不必只靠本地 zip/tgz。
- 源头合回卡片留在工作台；Handle 会自动路由；同一源头的冲突块会收成一条。
- 从源头分支创建新分支改为确认弹窗，不再在选择器里直接落盘。
- 文档站 Changelog 已同步本版说明。

## 新功能

- **合回冲突分诊**：工作台按自动干净 / 可自动合 / 过期 / 冲突 / 环境阻塞分类，替代逐行红卡片。
- **腾讯 SkillHub 远程查询**：Skills 面板按分类、关键词直连市场，安装后仍走本机 store 与授权链。
- **Qoder 技能市场**：与腾讯市场并列浏览、筛选和安装，详情弹窗样式对齐。
- **可拒绝的演示合回卡**：演示冲突出现在工作台，可以处理也可以关掉。
- **创建分支弹窗**：源头选择器里「创建分支」先确认名称，再从当前源头分出。

## 优化

- 工作台 Handle 会把合回卡片自动送到该去的桶。
- 同一源头的多段合回块会折叠，避免工作台被刷屏。
- 去掉工作区时保留该工作区下的会话，不会把对话一起删掉。
- 侧栏「添加工作区」收成紧凑图标，会话标题下伸笔画不再被裁切。
- Dock 猫标内缩，和相邻应用图标对齐。

## 修复

- 源头合回改用产品确认框，而不是浏览器原生弹窗。
- 演示合回冲突可以拒绝，不再卡死在工作台。
- SkillHub 与 Qoder 详情弹窗的间距和圆角对齐。

## CLI（仅命令行）

- 本 GitHub Release 同时发布 CLI 归档，版本与 Desktop 相同。
- 一等产物：`peer-darwin-arm64.tar.gz` / `peer-linux-x64.tar.gz`（内含 `peer` 与 `peer-credential-helper`，**必须同目录**）。
- 可通过 `npm i -g @peer-agent/cli@latest`（或 `pnpm add -g @peer-agent/cli@latest`）安装正式通道版本；`postinstall` 会拉取本版归档。
- 也可手动解压归档，将目录加入 `PATH`，执行 `peer --version` 校验后运行 `peer`。
- CLI 与 Desktop 继续共享 `~/.peer-agent` 下的会话和设置。

## Notes

- **Peer Agent 0.0.9** turns isolated-task merge-back into workbench triage: clean work merges itself, stale branches can be rebuilt, and only real conflicts wait for you.
- Desktop Skills can query Tencent SkillHub directly, and a Qoder marketplace sits beside it — you are not limited to local zip/tgz.
- Source merge cards stay on the workbench. Handle auto-routes them. Blocks from the same source collapse into one.
- Creating a branch from the source picker opens a confirm dialog instead of writing immediately.
- The docs-site Changelog includes this release.

## Features

- **Merge-conflict triage**: the workbench classifies auto-clean / auto-merge / stale / conflict / blocked-env, replacing per-line red cards.
- **Tencent SkillHub remote query**: the Skills panel talks to the catalog by category and keyword; installs still land in the local store and the grant chain.
- **Qoder skill marketplace**: browse, filter, and install next to SkillHub, with matching detail-dialog styling.
- **Declineable demo merge cards**: demo conflicts appear on the workbench and can be handled or dismissed.
- **Create-branch dialog**: “Create branch” in the source picker asks for a name before forking from the current source.

## Improvements

- Workbench Handle auto-routes merge cards into the right bucket.
- Same-source merge blocks collapse so the workbench is not flooded.
- Removing a workspace keeps its conversations instead of deleting the threads.
- The sidebar “add workspace” control is a compact icon; session-title descenders are no longer cropped.
- The Dock cat icon is inset so it matches neighboring app icons.

## Fixes

- Source merge-back uses the product confirm dialog, not a native browser prompt.
- Demo merge conflicts can be declined instead of sticking on the workbench.
- SkillHub and Qoder detail dialogs share spacing and radius.

## CLI (command-line only)

- This GitHub Release ships CLI archives under the same tag / version as Desktop.
- First-class assets: `peer-darwin-arm64.tar.gz` / `peer-linux-x64.tar.gz` (contains `peer` + `peer-credential-helper`; they **must stay in the same directory**).
- Install the stable channel with `npm i -g @peer-agent/cli@latest` (or `pnpm add -g @peer-agent/cli@latest`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
