## 说明

- **Peer Agent 0.0.5-beta.2** 跟进工作台产物预览和 Goal 交付：文件能用记住的编辑器打开，源码预览有语法高亮，验收卡会等到真正交付完再收起。
- 点 Goal Thread 轮次会跳到对应消息；长对话不再打开成空白间隔。
- 文档站 Changelog 已同步本版说明。

## 新功能

- **拆分打开**：预览顶栏改成拆分按钮，可用上次记住的编辑器打开当前文件，也能另选已安装应用，或打开所在文件夹 / 在 Finder 中显示。
- **源码高亮**：工作台 Source 模式复用现有 highlight.js，常见语言（如 jsx/tsx）有着色；未知语言或超过 20k 字符仍显示纯文本。

## 优化

- 任务产物显示真实文件名和 +N/−M，行号跟 unified diff 对齐，不再用「代码变更 / 新建文件」这类泛称，空预览也不再冒出假的 0。
- Goal 计划历史改成对齐的同级卡片，不再做成缩进树。

## 修复

- 长对话打开时虚拟回合跟真实视口对齐，不再先出现大块空白。
- 验收卡会等到交付真正完成再庆祝并收起；目标分支被挪走时改为变基跟上，冲突保留并提供重试。
- 在 Goal Thread 上点某一轮，会滚到对应消息，而不是只打开对话停在默认位置。
- 同一条流式输出不再被重复追加。

## CLI（仅命令行）

- 本版 GitHub Release 附带 CLI 归档（与 Desktop 同 tag / 同版本）。
- 可通过 `npm i -g @peer-agent/cli@beta`（或 `pnpm add -g @peer-agent/cli@beta`）安装 beta 通道版本；`postinstall` 会拉取本版归档。
- 也可手动解压归档，将目录加入 `PATH`，执行 `peer --version` 校验后运行 `peer`。
- CLI 与 Desktop 继续共享 `~/.peer-agent` 下的会话和设置。

## Overview

- **Peer Agent 0.0.5-beta.2** follows up workbench previews and Goal delivery: open files in the remembered editor, highlight source previews, and keep accept cards until delivery actually lands.
- Clicking a Goal Thread round jumps to the matching message; long chats no longer open as a blank spacer.
- The docs changelog is in sync with this release.

## What's New

- **Split open**: the preview header becomes a split control that opens the current file in the remembered editor, lets you pick another installed app, or opens the containing folder / reveals it in Finder.
- **Source highlighting**: workbench Source mode reuses the existing highlight.js highlighter so common files like jsx/tsx get token colors. Unknown languages and files over the 20k-character cap stay as plain text.

## Improvements

- Task artifacts show real filenames and +N/−M, with line numbers aligned to unified-diff hunks. Generic “code change / new file” labels are gone, and empty previews no longer paint a fake 0.
- Goal plan history renders as aligned sibling cards instead of an indented tree.

## Fixes

- Keep virtual turns aligned with the live viewport so a long thread no longer opens as a blank spacer.
- Keep accept cards visible until delivery actually finishes, then celebrate and dismiss. If the target branch moved, rebase onto it; conflicts stay visible with a retry path.
- Clicking a Goal Thread round scrolls to the matching message instead of only opening the conversation at the default position.
- Stop appending the same streaming delta twice.

## CLI (command-line only)

- This GitHub Release ships CLI archives under the same tag and version as Desktop.
- Install the beta channel with `npm i -g @peer-agent/cli@beta` (or `pnpm add -g @peer-agent/cli@beta`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
