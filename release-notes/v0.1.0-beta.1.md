## 说明

- **Peer Agent 0.1.0-beta.1** 是 0.1.0 的第一版预发布，走 beta 更新通道。正式版仍是 **0.0.18**。
- 这一版先放进后面「项目机器人」要用的地基。你现在打开应用，看到的还是原来的会话界面。
- 更新日志页面可以在「正式版」和「预发布」之间切换。预发布条目会标成「预发布」。

## 新功能

- 关掉窗口之后，正在进行的目标可以在后台继续推进。
- 需要你批准的操作会记下来。重新打开应用后仍然看得到；已经过期的批准会标明，而不是悄悄消失。
- 设置里新增「模型分工」：按工作类型选择模型。只有一个可用模型时，所有工作都用它。
- 需要看图的复核会尽量选用能看图的模型。

## 变更

- 开发者设置里增加「项目代理」开关。它只记住你的选择，打开之后界面和行为都不变。

## 已知限制

- 机器人列表、和机器人对话、记忆、并行任务、项目目标、远程查看都还没有开放。
- 项目代理还不能日常使用。

## 降级说明

- 可以重新安装 0.0.18，原来的会话可以打开。这一版不改写会话正文。
- 升级时会先备份设置，再写入版本号和稳定的项目 id。装回 0.0.18 时，这些新增字段会被旧版忽略。

## CLI（仅命令行）

- CLI 与 Desktop 共用 0.1.0-beta.1。终端里的 `peer` 仍是现在的会话 Agent，还不会打开项目机器人。
- 压缩包矩阵仍是 macOS ARM64 与 Linux x64。请把 `peer` 和 `peer-credential-helper` 放在同一目录。

locale:en-US

## Notes

- **Peer Agent 0.1.0-beta.1** is the first prerelease on the 0.1.0 line and uses the beta update channel. The stable release remains **0.0.18**.
- This build adds the foundation later project bots will use. The app you open is still the current conversation interface.
- The changelog page can switch between Stable and Pre-release. Pre-release entries are marked Pre-release.

## What's New

- A goal that is already running can keep going after you close the window.
- Approval requests are saved. They are still there after a restart, and an expired approval is marked instead of disappearing.
- Settings gain model routing: choose a model for each kind of work. When only one model is available, every kind of work uses it.
- A review that needs to look at an image prefers a model that can see images.

## Changes

- Developer settings gain a project-agent switch. It only stores the choice. Turning it on does not change the app.

## Known limits

- The bot list, bot conversations, memory, parallel tasks, project objectives, and remote viewing are not available.
- The project agent is not ready for daily use.

## Downgrade

- You can install 0.0.18 again and open your existing conversations. This prerelease does not rewrite conversation text.
- Upgrade backs up settings before it writes a schema version and stable project ids. 0.0.18 ignores those added fields.

## CLI (command-line only)

- The CLI shares version 0.1.0-beta.1 with Desktop. `peer` in the terminal is still the current conversation agent and does not open a project bot.
- The archive matrix remains macOS ARM64 and Linux x64. Keep `peer` and `peer-credential-helper` in the same directory.
