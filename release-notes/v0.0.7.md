## 说明

- **Peer Agent 0.0.7** 把工作区当前分支和会话任务线拆开：切会话不再像换了分支；未隔离时若 HEAD 对不上任务线，只提示继续会写在当前工作区。
- 新任务可在输入栏选择源头分支，不必先 checkout；任务结果页能看到本会话此前的 Goal。
- 侧栏会话改成平面列表行；工作区名称独占一行，路径放在第二行。
- CLI 支持 Fast 模式；窄屏 TUI 的 Goal 摘要改成 Now Playing。
- 文档站 Changelog 已同步本版说明。

## 新功能

- **源头分支**：新任务草稿可在输入栏选择并从工作区源头分叉，现有会话和已绑定任务线保持锁定。
- **工作区 HEAD / 任务线**：底栏和顶栏分开显示当前检出与本会话任务线或隔离标记。
- **历史 Goal**：任务结果页列出本会话此前的 Goal、状态、已完成工作和改过的文件。
- **CLI Fast**：ChatGPT / Grok OAuth 可打开 Fast；会话记住该选项，Responses 仅在准入且开关打开时发送 `service_tier=priority`。
- **TUI Now Playing**：窄屏 Goal 摘要改为一行当前任务、状态和 1/4 进度，不再堆 Goal 1/1、executing、百分比。

## 优化

- 侧栏会话行改为平面填充，不再浮起成胶囊；钉住移到行尾操作区。
- 工作区名称独占整行，路径换到第二行，避免 `peer...` 被路径挤掉。
- 侧栏标题跟随外观字体大小（与工作区目录同一档）。
- 打开会话落到最新消息，不再停在加载占位顶部。
- 启动时只预览工作区任务，按需再加载，不再为了计数拉全部会话。
- 大 Diff 悬停不再卡顿。
- TUI 流式不再额外缓冲 32ms；活动指示改为稳定的 `working...` 高光扫过。

## 修复

- 历史 Goal 缺少 `evidenceRefs` 时不再把界面打进错误边界。
- 同工作区 Goal 绑定后，隔离和输入栏芯片不再显示过期 HEAD。
- 过期的 Goal 交接不再被当成空模型回复。
- CLI 在 Responses 拆开 usage 细节时仍能记下 prompt cache 命中。
- 去掉侧栏工作区无用的圆形头像徽章。

## CLI（仅命令行）

- 本版 GitHub Release 附带 CLI 归档（与 Desktop 同 tag / 同版本）。
- 资产：`peer-darwin-arm64.tar.gz` / `peer-linux-x64.tar.gz`（内含 `peer` + `peer-credential-helper`，**必须同目录**）。
- 可通过 `npm i -g @peer-agent/cli@latest`（或 `pnpm add -g @peer-agent/cli@latest`）安装正式通道版本；`postinstall` 会拉取本版归档。
- 也可手动解压归档，将目录加入 `PATH`，执行 `peer --version` 校验后运行 `peer`。
- CLI 与 Desktop 继续共享 `~/.peer-agent` 下的会话和设置。

## Notes

- **Peer Agent 0.0.7** splits the workspace checkout from the conversation task line: switching chats no longer looks like a branch change. If the task is not isolated and HEAD does not match the task line, the UI only warns that writes stay on the current workspace.
- New tasks can pick a source branch in the composer without checking out first. The task result view lists earlier Goals in the same conversation.
- Sidebar conversations are flat list rows. The workspace name takes the first line; the path moves to the second.
- CLI adds Fast mode. Narrow TUI Goal summaries become a Now Playing row.
- The docs changelog is in sync with this release.

## What's New

- **Source branch**: new-task drafts can pick a workspace source in the composer; existing sessions and bound task lines stay locked.
- **Workspace HEAD / task line**: the footer and header show the current checkout separately from this session's task line or isolation mark.
- **Prior Goals**: the task result view lists earlier Goals in this conversation, with status, completed work, and files already touched.
- **CLI Fast**: ChatGPT / Grok OAuth can turn Fast on; sessions remember it, and Responses sends `service_tier=priority` only when admission and the flag are both on.
- **TUI Now Playing**: the compact Goal row leads with the current task, a status glyph, and 1/4 progress instead of Goal 1/1, executing, and percent.

## Improvements

- Sidebar conversation rows are a flat fill, not a lifted capsule; pin moves into the trailing actions.
- Workspace names use the full first line; the path sits on the second line so names are not truncated.
- Sidebar titles follow the appearance font scale at the same chrome size as the workspace tree.
- Opening a conversation lands on the latest messages instead of the loading placeholder.
- Startup shows a short workspace task preview and loads more on demand, instead of fetching every conversation for counts.
- Large diffs no longer hitch on hover.
- TUI streaming no longer waits on a 32ms buffer; activity uses a stable `working...` highlight sweep.

## Fixes

- Historical Goals that omit `evidenceRefs` no longer crash the renderer error boundary.
- Same-workspace Goal bindings no longer leave isolation or the composer chip on a stale HEAD.
- Stale Goal handoff is no longer treated as an empty model reply.
- CLI still records prompt-cache hits when Responses splits usage details.
- Unused circular workspace avatar badges are gone.

## CLI (command-line only)

- This GitHub Release includes CLI archives (same tag / version as Desktop).
- Assets: `peer-darwin-arm64.tar.gz` / `peer-linux-x64.tar.gz` (contains `peer` + `peer-credential-helper`; **must stay in the same directory**).
- Install the stable channel with `npm i -g @peer-agent/cli@latest` (or `pnpm add -g @peer-agent/cli@latest`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
