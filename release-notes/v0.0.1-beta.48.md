## 说明

- 本版在 **0.0.1-beta.47** 之上，聚焦 Provider 配置体验、Qoder 上下文档位正确性、用量统计口径，以及 Goal / 浏览器工作台的稳定性。
- 自动更新通道默认从 beta 毕业到 **stable**；需要继续跟踪预发版的用户可在设置中改回 beta。

## 新功能与体验优化

- **统一 Provider 目录**：连接模型支持服务模板（service templates）与目录动效，配置入口更一致。
- **OAuth 不再卡住设置页**：模型 / 通道列表先返回本地数据，后台静默刷新凭证，凭证变更后再增量刷新 UI。
- **会话绑定 Browser 面板**：可为当前会话打开绑定的浏览器工作台。
- **Qoder 私有通道文案**：设置页将 private channel 标为 **本地 CLI**，并补充连接前提说明。

## 稳定性修复

- **Qoder 上下文档位投影**：档位可用窗口按「能装下 max_input 的最小档」锚定预留，1M 档不再错误坍缩成 180k。
- **恢复会话后窗口容量**：打开旧会话时按当前模型档位重投影 `contextWindow`，占用 token 仍沿用快照，避免 UI 一直显示旧的 180k。
- **用量统计**：按通道聚合 Provider，而不是按模型条目 UUID；「按模型」展示配置的 `modelLabel`。
- **Goal 回合计时**：Goal Runner 流 remap 时保持 `turnStartedAt`，计时器不再被重置。
- **Goal 权限门禁**：允许新的命令请求通过权限门，避免合法能力被误拦。
- **ChatGPT 订阅定价回填**：停止 models.dev 价格回填抖动。
- **UI 细节**：统一 modal 毛玻璃、tooltip / 侧栏 branch badge 圆角。

## 发布与通道

- **自动更新默认 stable**：已安装用户的自动更新通道从 beta 毕业到 stable release。
- GitHub Releases 继续提供 Desktop 与 CLI 产物；CLI 安装：`npm i -g @peer-agent/cli@beta`。
- `peer --version` 应输出 `peer 0.0.1-beta.48`。

## Overview

- Built on **0.0.1-beta.47**, this beta focuses on provider setup UX, correct Qoder context-tier projection, usage-stats grouping, and Goal / Browser stability.
- The auto-update channel now graduates from beta to **stable** by default; stay on beta only if you explicitly keep the pre-release channel.

## Features and UX improvements

- **Unified provider catalog**: connect-a-model flow gains service templates and catalog motion for a more consistent setup surface.
- **OAuth no longer blocks settings**: model / channel lists return local data first; silent credential refresh runs in the background and the UI re-fetches only when credentials actually change.
- **Conversation-bound Browser panel**: open a Browser workbench bound to the current conversation.
- **Qoder private channel copy**: settings label the private channel as **local CLI** and document connect prerequisites.

## Reliability fixes

- **Qoder context-tier projection**: input reserve anchors to the smallest tier that fits `max_input_tokens`, so a selected 1M tier no longer collapses to ~180k.
- **Restored context window capacity**: reopening a conversation reprojects `contextWindow` from the live model tier while keeping occupied tokens from the snapshot (no more stale 180k UI).
- **Usage stats**: group by channel instead of model-entry UUID; By Model shows the configured `modelLabel`.
- **Goal turn timer**: keep `turnStartedAt` across Goal Runner stream remaps so the timer no longer resets mid-run.
- **Goal permission gate**: allow fresh command requests through the permission gate instead of blocking legitimate capabilities.
- **ChatGPT subscription pricing**: stop models.dev pricing backfill thrash.
- **UI polish**: unify modal frosted glass and chip/panel radii for tooltips and sidebar branch badges.

## Release channel

- **Auto-update defaults to stable**: installed clients graduate the updater channel from beta to stable.
- GitHub Releases continue to ship Desktop and CLI artifacts. CLI install: `npm i -g @peer-agent/cli@beta`.
- `peer --version` should print `peer 0.0.1-beta.48`.
