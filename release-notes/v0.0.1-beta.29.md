## 新功能

- **长回复时用户消息保持置顶**：AI 长时间回复过程中，你发出的那条消息会稳定停留在可视区顶部，方便对照上下文。
- **聊天回合上下文改进**：优化多轮对话的上下文组织与处理详情的呈现。

## 优化

- 引入 runtime-core 核心包，统一能力注册、权限合并、生命周期 Hook 与证据处理逻辑，为后续稳定性打基础。
- 改进 compaction（上下文压缩）状态处理。
- 思考区在完成后自动折叠，界面更清爽。

## 修复

- 修复聊天自动滚动的动画抖动问题（改为无动画即时定位）。
- 修复 ChatGPT 订阅标签未本地化的问题。
- 修复输入框队列在多会话间串扰的问题（现按会话隔离）。

## What's New

- **Keep the user message pinned during long replies**: While the AI streams a long answer, your last message stays at the top of the viewport for easier comparison.
- **Better turn context**: Improved multi-turn context organization and how processing details are presented.

## Improvements

- Introduced the runtime-core package to unify capability registration, permission merge, lifecycle hooks, and evidence handling.
- Improved compaction state handling.
- Thinking panels auto-collapse when finished for a cleaner UI.

## Fixes

- Fixed chat auto-scroll jank (instant reposition without animation).
- Localized the ChatGPT subscription label.
- Isolated the composer queue per session so multi-session use no longer crosstalks.
