## 发布状态

- **0.1.0-rc.13** 修复图片授权无法传给子 Agent、核验长时间等待及具体操作许可被扩大的问题，并整理回复详情与服务商设置。正式版仍为 0.0.18；本版用于继续评测。

## 图片授权与任务继承

- 项目外图片进入正式的本地授权流程。“仅这一次”只批准当前读取；“本轮允许此图片”限定具体文件、工作区和当前机器人，30 分钟内可供其子 Agent、核验者及重启恢复使用。授权入口说明图片会交给当前模型。
- 不同机器人、工作区、文件或已变化的文件不会沿用该许可；任务取消、暂停、被取代以及授权过期、撤回后拒绝读取。普通聊天中的同意和旧批准记录不自动成为图片许可。
- 一次文件或命令批准不扩大成同类操作通行证。复用许可绑定具体能力、参数和执行身份；授权条只处理当前展示请求，不批量批准其他排队请求。并发回合独立保存权限上下文。

## 核验与界面

- 委托核验具备五分钟整体截止时间，并正确处理父任务取消、权限拒绝和迟到结果。没有有效授权且无法请求确认时及时返回拒绝，避免长时间停在“核验中”。
- 回复详情更紧凑，最新执行步骤优先显示，取消后的文件读取不再把缺失结果显示成 null。服务商设置使用统一的 Frost 分组与圆角。
- TUI 的许可复用同样绑定具体操作与工作区，并重检角色、取消和租约。默认 TUI 尚无内置本地图片 Provider。

## 升级与回退

- RC4–RC12 可在“设置 → 更新与关于”通过自动或 Beta 通道检查 RC13；旧 Beta5/RC1–RC3 请下载匹配架构的安装包手动升级。
- 退出旧宿主，备份完整数据根，Desktop、CLI/TUI 与 Gateway 同步升级。npm 固定版本为 `@peer-agent/cli@0.1.0-rc.13`；归档中的 peer 与凭据助手保持同目录。
- 回退时恢复升级前的完整备份，另存新数据与产物。不要让旧版本直接写入新版数据目录；升级不需要重置数据。

## 验证范围与限制

- 权限回归覆盖实际图片 Provider 像素侧带、Bot → Worker → Verifier → 重启恢复，以及越权、撤回和失败路径；模型与解码适配器为受控测试。产品截图由实施者自审，不称独立审查。
- 本版不自动批准历史截图、接管旧任务或改写旧完成事实。真实云模型看图质量、Windows/Linux 交互安装、完整读屏、复杂外部写入与长期日用仍需相应验收；总体 Ready 与 GA 未宣告通过。

## Release status

- **0.1.0-rc.13** fixes image-permission inheritance, prolonged delegated verification and overly broad reuse of operation approvals. It also refines reply details and provider settings. Stable remains 0.0.18; this release is for continued evaluation.

## Image permission and task inheritance

- Images outside the project enter the formal local approval flow. “Allow once” approves the current read only. “Allow this image for this round” binds the exact file, workspace and current Bot for 30 minutes, including its child Agents, verifier and restart recovery. The prompt explains that the image is sent to the current model.
- Different Bots, workspaces, files or changed files cannot reuse that permission. Cancelled, paused or superseded tasks and expired or revoked grants are rejected. Agreement in ordinary chat and historical approval records do not automatically authorize image reads.
- A single file or command approval no longer grants access to similar operations. Reuse binds the capability, arguments and execution identity. Approval controls decide only the displayed request; other queued requests remain pending. Concurrent turns keep separate permission contexts.

## Verification and interface

- Delegated verification has a five-minute overall deadline and handles parent cancellation, permission denial and late results. When no valid grant or approval interface exists, it returns a denial promptly instead of remaining in verification indefinitely.
- Reply details are more compact and show the latest execution steps first. Cancelled file reads no longer render missing results as null. Provider settings use consistent Frost groups and radius tokens.
- TUI approval reuse also binds the exact operation and workspace, with role, cancellation and lease checks. The default TUI does not yet include a local image Provider.

## Upgrade and rollback

- RC4–RC12 can check for RC13 through Auto or Beta in Settings → Update & About. Older Beta5/RC1–RC3 require a manual installer matching their architecture.
- Quit older hosts, back up the complete data root and upgrade Desktop, CLI/TUI and Gateway together. Use `@peer-agent/cli@0.1.0-rc.13` for a fixed npm version. Keep peer and its credential helper together.
- Roll back using the complete pre-upgrade backup while retaining new data and artifacts separately. Older versions must not write into the newer data directory. Upgrading does not require a reset.

## Validation scope and limits

- Permission regression covers actual image Provider pixel sidebands, Bot → Worker → Verifier → restart, and unauthorized, revoked and failure paths with controlled model and decoder adapters. Product screenshots receive implementer self-review, not independent review.
- This release does not automatically approve historical screenshots, take over old tasks or rewrite completion facts. Live cloud vision quality, interactive Windows/Linux installation, full screen-reader coverage, complex external writes and long-term use still require their corresponding acceptance. Overall readiness and GA are not declared complete.
