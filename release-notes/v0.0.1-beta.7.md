## 优化

- 更新弹窗的「更新内容」现在支持富文本展示，不再出现 `<p>` 等原始标签。
- 发布说明改为按版本维护，发布前会自动校验，确保每个版本都有清晰的更新内容。

## 修复

- 修复自动更新下载失败（404）的问题：此前更新清单中的下载链接与实际安装包文件名不一致，导致无法下载新版本。
- 修复「发现新版本」弹窗中更新内容显示为 HTML 源码的问题。

## Improvements

- Release notes in the update modal now render as rich text instead of raw tags like `<p>`.
- Release notes are maintained per version and validated before publish so every release has clear update content.

## Fixes

- Fixed auto-update download failures (404) caused by mismatched download URLs and installer filenames in the update manifest.
- Fixed the “New version available” modal showing release notes as raw HTML source.
