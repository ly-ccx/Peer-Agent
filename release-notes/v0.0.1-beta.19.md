## 新功能

- **MCP 一键 OAuth 登录**：HTTP 类型的 MCP 服务新增一键 OAuth 登录入口，可自动跳转授权，接入需要身份验证的服务更顺畅。

## 优化

- **Plan 模式**：原「Goal 模式」正式更名为「Plan 模式」（含工作台标签与内部标识），命名更贴合“先规划再执行”的实际体验，并保持向后兼容。
- **上下文用量统计更准**：上下文计数口径重新梳理，压缩后能正确回落，长会话的用量显示更真实可信（ADR 42）。
- **Plan 审批卡对齐**：聊天流中的「批准并执行」审批卡与聊天内容列居中对齐，视觉更整齐。
- **任务推进更稳**：Plan 模式任务推进不再受固定次数/轮次上限熔断，改由“无进展”双信号护栏判定停止，复杂任务更不容易被中途打断。

## 修复

- 修复重载应用后，需要身份验证的 MCP 服务未稳定显示登录引导的问题。
- 修复运行中的会话仍显示置顶操作的问题。
- 修复 Plan 面板指示箭头方向的显示细节。
- 优化聊天流订阅的内部实现，提升多会话并发时流式消息路由的稳定性。
