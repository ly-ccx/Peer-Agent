## 说明

- 本版在 **0.0.1-beta.43** 之上，把默认模式升级为 **Agent 自驱**，并补齐 macOS 菜单栏托盘、Skills 工作区分层、首启配模型与产品文档站。
- Desktop 与 CLI 的模式产品面统一为 **Agent / Plan**；旧 `goal` 会话仍兼容，显示为 Agent。

## 新功能

- **默认 Agent 模式**：默认入口按任务深度自动规划并执行（L0–L3），多步任务可自建 Goal 脚手架并证据闭环；Plan 仍保留「先批再做」。
- **工程诊断门**：症状类问题（糊/慢/不准等）在动手前要求问题重写、根因假设与验收方式，减少用户当 QA。
- **macOS 菜单栏托盘**：菜单栏常驻图标，快速查看近期会话并唤起应用；托盘 Template 图标与加载链路一并补齐。
- **Skills 分层与详情**：区分全局 / 工作区 Skills，能力台增加详情对话框，便于查看与管理。
- **首启配模型**：空会话提供首次模型配置路径，配好即可发送，无需重启。
- **产品文档站**：GitHub Pages 落地页、变更日志站与更密的产品文档内容。

## 优化

- **Desktop / CLI 模式统一**：模式切换只暴露 Agent 与 Plan；旧 goal 兼容显示为 Agent，自驱能力不降级。
- **写入与流式稳定性**：限制 `write_file` 体量，提高流空闲超时，降低大写入与长流中断风险。
- **文档与变更展示**：Changelog 页加宽内容区，产品文档内容更紧凑可读。

## 修复

- **CLI 多图粘贴**：多张同名（不同目录）图片不再折叠成一张；发送正文不再残留本地路径字符串。
- **CLI 模式选择器**：不再单独露出 Goal 入口；快捷键与面板与 Desktop 产品语义对齐。
- **压缩连续性**：修复压缩过程中连续性上下文丢失。
- **推理状态文案**：避免 GPT 流式 thinking 状态短语粘连。
- **侧栏空态闪烁**：刷新会话列表时不再错误闪「无会话」；侧栏边缘视觉更柔和。
- **其他**：协议包测试产物不进入 npm dist；若干 UI / 会话滚动相关回退与整理。

## CLI / npm

- 本版 GitHub Release 继续附带 CLI 归档（与 Desktop 同 tag）：`peer-darwin-arm64.tar.gz`。
- 可安装：`npm i -g @peer-agent/cli@beta`。
- 安装后执行 `peer --version` 应输出 `peer 0.0.1-beta.44`。
- 会话与设置仍落在 `~/.peer-agent`，与 Desktop 共享。

## Notes

- Built on **0.0.1-beta.43**. Default mode is now **Agent** (self-driven), with a macOS menu-bar tray, workspace/global Skills, first-run model setup, and a product docs site.
- Desktop and CLI product surface is **Agent / Plan**. Legacy `goal` sessions remain compatible and display as Agent.

## What's New

- **Default Agent mode**: Adapts planning depth (L0–L3), can scaffold Goals for multi-step work with evidence-based completion; Plan stays approval-gated.
- **Diagnosis gate**: Symptom-style issues require problem rewrite, root-cause hypotheses, and success checks before side-effecting fixes.
- **macOS menu-bar tray**: Persistent tray icon for recent sessions and quick app activation; tray template assets and load path included.
- **Skills scope & detail**: Split global vs workspace Skills; capability workbench adds a detail dialog.
- **First-run model setup**: Empty chat offers a first-time model configuration path so you can send without restarting.
- **Product docs site**: GitHub Pages landing, changelog site, denser product documentation.

## Improvements

- **Unified mode surface**: Mode picker exposes only Agent and Plan; legacy goal maps to Agent without losing self-driven behavior.
- **Write & stream robustness**: Caps `write_file` payload size and raises stream idle timeout.
- **Docs presentation**: Wider changelog content measure and denser product docs copy.

## Fixes

- **CLI multi-image paste**: Same-basename images in different folders no longer collapse to one attachment; local path strings no longer leak into message text.
- **CLI mode picker**: Goal is no longer a separate selectable product mode; shortcuts/panel match Desktop.
- **Compaction continuity**: Continuity context is preserved during compaction.
- **Reasoning status text**: Prevents glued GPT streamed thinking status phrases.
- **Sidebar empty flash**: Conversation list no longer flashes an empty state during refresh; softer sidebar edge.
- **Other**: Keep protocol test artifacts out of npm package dist; assorted UI/scroll cleanups and reverts.

## CLI / npm

- This GitHub Release continues to ship a CLI archive alongside Desktop: `peer-darwin-arm64.tar.gz`.
- Install: `npm i -g @peer-agent/cli@beta`.
- After install, `peer --version` should print `peer 0.0.1-beta.44`.
- Sessions and settings still live under `~/.peer-agent` and are shared with Desktop.
