## 发布状态

- **0.1.0-rc.15** 修复完全访问下反复请求图片授权，以及旧核验中断后无法继续回复的问题，并更新小猫状态栏图标。正式版仍为 0.0.18，本版用于继续评测。

## 完全访问与连续看图

- 尊重已选择的“完全访问”：主机器人及其任务、核验者使用同一套本地授权判断，连续读取不同图片不再被额外改成逐张询问。
- 图片像素在主动让出和后续回合继续时保持可用；重启后重新读取仍按当前权限检查，撤回授权后不能复用旧图片上下文。
- 询问模式继续显示具体图片权限卡，支持授权后继续原读取、拒绝、取消、停止和超时。完全访问不改变主机器人的只读能力边界，也不代替任务验收。

## 中断后的工作恢复

- 工具已经返回结果时，先保存检查点再响应取消，减少已知结果被误记为未知的情况。
- 对已中断的旧核验，宿主核对原任务归属和实际运行状态后，可以沿原任务与检查点继续；预算、历史与待处理事件保留。
- 核对中断不等于核验通过。无法确定结果的写入、命令和外部操作仍会阻断，避免重试造成重复执行。

## 界面与文档

- 状态栏使用清晰的小猫线稿，保留 macOS 自动反色、Retina 清晰度和待处理数量。
- 取消任务后，在原按钮真正移除时归还键盘焦点；用户已移走焦点时不抢回。
- 同步中英文 README、使用文档、发布说明和站点更新日志。

## 升级与验证范围

- 升级前备份完整数据根，Desktop、CLI/TUI 与 Gateway 同步升级；回退使用完整升级前备份。无需重置数据或重新选择已有权限设置。
- 源码检查覆盖旧记录的隔离恢复、真实图片 Provider 与正常 HTTP 请求中的像素传递、重启、权限生命周期及桌面交互。模型认知使用受控适配器；不代表真实云模型视觉质量。
- 产品截图由实施者自审，非独立审查。Windows/Linux 交互安装、完整读屏、长期日用和正式版验收仍需单独完成。

## Release status

- **0.1.0-rc.15** fixes repeated image approvals under full local access and replies blocked by interrupted historical verification, and refreshes the cat menu-bar icon. Stable remains 0.0.18; this prerelease is for continued evaluation.

## Full access and consecutive images

- Honor the selected full local access setting across the main Bot, its tasks and verification. Reading different images consecutively no longer adds an extra approval prompt for each file.
- Preserve image pixels across cooperative yields and continued turns. Reads after restart still check current authorization, and revoked access cannot reuse an old image context.
- Ask mode retains exact-image cards with continuation, rejection, cancellation, stop and timeout. Full access does not expand the main Bot's read-only capability boundary or accept task results.

## Continuing interrupted work

- Persist results already returned by tools before responding to cancellation, reducing false unknown-outcome records.
- The host can reconcile an interrupted historical verification against its original ownership and actual running state, then continue the original work and checkpoint with its budget, history and pending events preserved.
- Reconciliation does not mean verification passed. Unknown writes, commands and external operations remain blocked to prevent duplicate execution.

## Interface and documentation

- Use a clear cat outline in the menu bar while preserving macOS template inversion, Retina rendering and the pending count.
- Restore keyboard focus when the cancelled task's action actually disappears, without reclaiming focus the user has already moved.
- Synchronize bilingual READMEs, usage guidance, release notes and the generated site changelog.

## Upgrade and validation scope

- Back up the complete data root and upgrade Desktop, CLI/TUI and Gateway together. Rollback requires the complete pre-upgrade backup. No data reset or reselection of existing access settings is required.
- Source checks cover isolated recovery of historical records, actual image Provider pixels in normal HTTP requests, restart, permission lifecycles and desktop interaction. Cognition is controlled; these checks do not establish real cloud vision quality.
- Product screenshots receive implementer self-review, not independent review. Interactive Windows/Linux installation, full screen-reader coverage, long-term daily use and stable-release acceptance remain separate gates.
