## 说明

- **Peer Agent 0.0.1** 是首个正式版（`latest` 通道）。
- 本版**集结 `0.0.1-beta.7` → `0.0.1-beta.49` 整条 beta 线**中已验证、可对外交付的能力，而不是只记录 beta.49 这一次增量。
- beta.49 仅是冻结点；正式版说明按产品面汇总整条 beta 历程。
- 端侧本地 LLM 推理（Local Agent Runtime）仍在推进中，详见项目 Roadmap。

## 能力总览（beta 全线集结）

### 产品与工作流

- **Desktop + CLI**：桌面壳与 `peer` 终端入口并行演进，共享核心运行时与配置口径。
- **Agent / Plan 自驱工作流**：计划创建、子任务推进、证据回写与下一步操作入口。
- **会话体验**：流式输出、思考展示、上下文压缩可追踪、长会话稳定性、附件与队列消息能力持续打磨。
- **用量与配额**：用量统计、订阅配额展示、Desktop / CLI 口径统一。

### 连接与扩展

- **Provider 连接中心**：官方 API、授权登录、自定义兼容与第三方 / Coding Plan 模板。
- **品牌与目录体验**：提供商 / 模型图标、深色主题目录、添加渠道居中 Modal（模板锁定渠道与鉴权）。
- **第三方 / 套餐渠道沉淀**：DeepSeek 官方、GLM Coding Plan（国区 / 国际区）、Kimi / Moonshot、MiniMax（CN / Global）、火山方舟、小米 MiMo / Token Plan、阿里云百炼 Coding Plan、OpenCode Go 等。
- **MCP**：本地 MCP 管理、OAuth、卡片式连接与工具开关。

### 安全与稳定性

- **危险操作确认**：删除渠道等操作二次确认。
- **凭证本地安全路径**：系统钥匙串等本地保管。
- **Browser 工作台**：工作区注册就绪后再操作；截图可进入视觉上下文。
- **运行时治理**：压缩、用量、流式复读守卫、主进程 / 更新链路等持续修复。

## 安装与通道

- **Desktop**：从 GitHub Releases 的 `v0.0.1` 资产安装对应平台包。
- **CLI**：`npm i -g @peer-agent/cli@latest`（或 `npm i -g @peer-agent/cli@0.0.1`）。
- `peer --version` 应输出 `peer 0.0.1`。
- 若从任意 `0.0.1-beta.*` 升级，建议先备份本机 Provider / MCP 配置。

## 致谢

感谢 beta 全线试用与反馈。0.0.1 是这条 beta 线的毕业版；后续新功能在 `0.0.2-beta` 线继续迭代。

## Overview

- **Peer Agent 0.0.1** is the first stable release (`latest` channel).
- This release **graduates the entire `0.0.1-beta.7` → `0.0.1-beta.49` beta line**, not just the delta from beta.49.
- beta.49 is only the freeze point; the stable notes summarize the product surface proven across the full beta series.
- On-device LLM inference (Local Agent Runtime) remains in progress — see the project Roadmap.

## Capability summary (full beta graduation)

### Product and workflows

- **Desktop + CLI**: desktop shell and the `peer` terminal entry evolved together with a shared runtime and config model.
- **Agent / Plan workflows**: plan creation, subtask progress, evidence write-back, and next-step actions.
- **Conversation UX**: streaming, reasoning display, trackable context compression, long-session stability, attachments, and queued messages.
- **Usage and quota**: usage stats, subscription quota display, and aligned Desktop / CLI accounting.

### Connectivity and extensions

- **Provider connection center**: official API, OAuth sign-in, custom compatible providers, and third-party / coding-plan templates.
- **Catalog UX**: provider/model brand icons, dark-theme catalog, and a locked centered modal for add-provider setup.
- **Third-party / coding-plan channels**: DeepSeek official, GLM Coding Plan (CN / Global), Kimi / Moonshot, MiniMax (CN / Global), Volcengine Ark, Xiaomi MiMo / Token Plan, Aliyun Bailian Coding Plan, OpenCode Go, and more.
- **MCP**: local MCP management, OAuth, card-style connections, and tool toggles.

### Safety and reliability

- **Confirm dangerous actions**: confirm before removing provider channels.
- **Local credential security**: OS keychain and other local secure paths.
- **Browser workbench**: wait for workspace registration; screenshots can feed visual context.
- **Runtime hardening**: compression, usage, stream-loop guards, main-process and update-path fixes.

## Install and channel

- **Desktop**: install the platform package from the `v0.0.1` GitHub Release assets.
- **CLI**: `npm i -g @peer-agent/cli@latest` (or `npm i -g @peer-agent/cli@0.0.1`).
- `peer --version` should print `peer 0.0.1`.
- If upgrading from any `0.0.1-beta.*`, back up local Provider / MCP settings first.

## Thanks

Thanks to everyone who tested the beta line. 0.0.1 is the graduation of that series; new work continues on the `0.0.2-beta` line.
