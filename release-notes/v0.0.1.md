## 说明

- **Peer Agent 0.0.1** 是首个正式版（latest 通道），基于 **0.0.1-beta.49** 冻结。
- 本版本将 beta 系列中已验证的能力与连接体验收敛为稳定发布：Desktop / CLI / Agent·Plan 工作流、Provider 目录与第三方套餐渠道、Browser 工作台，以及 MCP 本地能力路径。
- 端侧本地 LLM 推理（Local Agent Runtime）仍在推进中，详见项目 Roadmap。

## 功能概览

- **Desktop 与 CLI**：桌面壳 + `peer` 终端入口；Agent / Plan 自驱工作流。
- **Provider 连接中心**：官方 API、授权登录与第三方 / Coding Plan 模板；品牌图标；添加渠道时以居中 Modal 配置，模板锁定渠道与鉴权。
- **第三方 / 套餐渠道**：DeepSeek 官方、GLM Coding Plan（国区 / 国际区）、Kimi / Moonshot、MiniMax（CN / Global）、火山方舟、小米 MiMo / Token Plan、阿里云百炼 Coding Plan、OpenCode Go 等。
- **安全与确认**：删除渠道需二次确认；凭证走系统钥匙串等本地安全路径。
- **Browser 工作台**：工作区注册就绪后再操作；截图可进入视觉上下文。

## 安装与通道

- **Desktop**：从 GitHub Releases 的 `v0.0.1` 资产安装对应平台包。
- **CLI**：`npm i -g @peer-agent/cli@latest`（或 `npm i -g @peer-agent/cli@0.0.1`）。
- `peer --version` 应输出 `peer 0.0.1`。

## 致谢

感谢 beta 期间所有反馈与试用。若从 beta 升级，建议先备份本机 Provider 配置后再安装正式版。

## Overview

- **Peer Agent 0.0.1** is the first stable release (latest channel), frozen from **0.0.1-beta.49**.
- This release stabilizes the capability surface proven in beta: Desktop / CLI, Agent·Plan workflows, provider catalog and third-party coding-plan channels, Browser workbench, and local MCP capability paths.
- On-device LLM inference (Local Agent Runtime) remains in progress — see the project Roadmap.

## Highlights

- **Desktop and CLI**: desktop shell plus the `peer` terminal entry; Agent / Plan self-driven workflows.
- **Provider connection center**: official API, OAuth sign-in, and third-party / coding-plan templates; brand icons; locked modal setup that keeps channel and auth bound to the selected template.
- **Third-party / coding-plan channels**: DeepSeek official, GLM Coding Plan (CN / Global), Kimi / Moonshot, MiniMax (CN / Global), Volcengine Ark, Xiaomi MiMo / Token Plan, Aliyun Bailian Coding Plan, OpenCode Go, and more.
- **Safety**: confirm before removing a provider channel; credentials stay on local secure paths such as the OS keychain.
- **Browser workbench**: wait for workspace registration before actions; screenshots can feed visual context.

## Install and channel

- **Desktop**: install the platform package from the `v0.0.1` GitHub Release assets.
- **CLI**: `npm i -g @peer-agent/cli@latest` (or `npm i -g @peer-agent/cli@0.0.1`).
- `peer --version` should print `peer 0.0.1`.

## Thanks

Thanks to everyone who tried the beta series and shared feedback. If upgrading from beta, back up local provider settings before installing the stable build.
