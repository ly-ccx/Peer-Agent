## 新功能

- 工作台新增**内嵌浏览器**：可像普通浏览器一样在面板内访问网页（地址栏、前进/后退/刷新/停止、加载与错误提示）；同时支持 **Agent 操控浏览器**（导航、点击、输入、截图、读取页面），操作均经权限确认。
- Diff 面板支持一键**切换查看文件完整内容**：除查看改动外，可直接查看目标文件完整文本（带行号、只读）。

## 优化

- 应用更新改为**后台静默下载**：不再全屏霸屏，下载完成后右下角弹卡片，点击即可安装，关闭/弹出均带动画。
- 底部状态栏的**轮次与工具调用计数**实时反映真实执行进度。
- 自动压缩历史时的**进度显示更准确**。
- 收紧工作台顶部留白，Diff 标题栏上提铺满，界面更紧凑。

## 修复

- 修复查找框**输入框与向上箭头无法点击**的问题。
- 修复 mac 端更新下载在部分网络环境下失败的问题（改走系统代理）。
- 修复历史长文本预览条**无内容时点不开**，并压成单行展示。
- 修复 Markdown 列表的**圆点/序号丢失**问题。
- 修复目标计划在特定情况下残留**僵尸“执行中”计划**的问题。
- 文件搜索越权路径现在统一经过**权限确认**，更安全。

## What's New

- Workbench adds an **embedded browser**: browse pages in-panel (address bar, back/forward/reload/stop, loading and error states); **Agent can drive the browser** (navigate, click, type, screenshot, read page) with permission confirmation.
- Diff panel can **switch to full file content** in one click: beyond the patch, view the full target file (line numbers, read-only).

## Improvements

- App updates use **silent background download**: no full-screen takeover; a bottom-right card appears when ready to install, with enter/exit animations.
- Bottom status bar **turn and tool-call counts** reflect real progress live.
- Auto-compaction progress is **more accurate**.
- Tighter workbench top padding and a flush Diff title bar for a denser UI.

## Fixes

- Fixed the find box where the input and up-arrow could not be clicked.
- Fixed macOS update downloads failing on some networks by using the system proxy.
- Fixed long-history preview bars that would not open when empty, and collapsed them to a single line.
- Fixed missing Markdown list bullets/numbers.
- Fixed zombie “running” goal plans in certain cases.
- Out-of-scope file search paths now go through **permission confirmation**.
