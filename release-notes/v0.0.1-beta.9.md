## 新功能

- 自动检查更新：应用运行期间每小时自动检查一次新版本，发现更新时会在左下角版本号旁亮起红点提示。

## 优化

- 侧边栏版本号去掉了外层胶囊边框，视觉更简洁。
- 弹窗关闭时新增自然的退场动画，不再瞬间消失。
- 重新设计了 batch_search（批量搜索）工具卡片，更简洁清晰。

## What's New

- Automatic update checks: while the app is running it checks for a new version every hour, and shows a red badge next to the version number when one is available.

## Improvements

- Removed the capsule border around the sidebar version label for a cleaner look.
- Added a natural exit animation when closing modals instead of an abrupt disappear.
- Redesigned the batch_search tool card to be simpler and clearer.
