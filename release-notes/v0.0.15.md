## 说明

- **Peer Agent 0.0.15** 是桌面体验与稳定性更新，聚焦任务信息卡、后台运行详情和聊天内容查看。

## 优化

- 任务信息卡按产出、来源与工具、活动后台任务、环境组织内容；环境按需展开，文件和网页来源打开对应对象。
- 当前会话只展示实际使用的工具和仍在运行的后台任务。运行详情使用统一图标和紧凑字号，命令、日志、技术信息与停止确认分层呈现。
- 渠道卡片统一展开入口，余额与用量分别展示。
- 图片预览统一为共用灯箱，减少不同入口的体验差异。
- 改善窄窗口、Workbench 双面板及置顶问题与任务卡的布局；任务进度入口显示计划名称。

## 修复

- 切换会话时清理旧任务卡的展开状态与运行详情，区分当前分支和任务起始分支。
- 修复长 TS / TSX 源文件预览失去语法高亮的问题。
- 上下文压缩期间不再显示误导性的流式光标。
- 修复中断后等待用户回复的计划无法正确消费回复的问题；恢复中断计划时默认继续执行，不再沿用旧的阻塞意图。
- 同步中英文更新日志和文档站，补充任务信息卡的使用说明。
- 修复文件树刷新中的目录名类型检查，并改善打开 Workbench 后的聊天标题栏底色。

## CLI（仅命令行）

- CLI 与 Desktop 共用 0.0.15 版本号。本版 CLI 压缩包矩阵为 macOS ARM64、Linux x64；不提供 Windows CLI 压缩包，最终以 Release 资源为准。
- 请将压缩包中的 `peer` 与 `peer-credential-helper` 保存在同一目录。Desktop 提供 macOS、Windows 和 Linux 安装包。

## Notes

- **Peer Agent 0.0.15** is a desktop experience and reliability update focused on task information, background run details, and viewing chat content.

## Improvements

- The task information card groups outputs, sources and tools, active background tasks, and on-demand environment settings. File and web sources open their exact targets.
- Each conversation shows tools actually used and active background tasks. Run details use consistent icons and compact typography, with separate command, logs, technical information, and stop confirmation sections.
- Channel cards use a consistent expansion entry and separate balance from usage.
- Image preview entries share one lightbox experience.
- Narrow windows, the open Workbench, and pinned questions fit better alongside the task card; the task progress entry shows the plan name.

## Fixes

- Switching conversations clears stale expansion and run details. The current branch is distinguished from the task starting branch.
- Long TS / TSX source previews retain syntax highlighting.
- Context compaction no longer shows a misleading streaming cursor.
- Interrupted plans waiting on the user correctly consume replies; resuming an interrupted plan defaults to execution instead of retaining a stale blocked intent.
- Updated bilingual release history and site documentation with task information card guidance.
- Fixed directory-name type checking during file-tree refresh and improved the chat header background with Workbench open.

## CLI (command-line only)

- CLI and Desktop share version 0.0.15. CLI archives target macOS ARM64 and Linux x64; no Windows CLI archive is provided. Consult the actual Release assets for availability.
- Keep `peer` and `peer-credential-helper` in the same directory. Desktop installers are provided for macOS, Windows, and Linux.
