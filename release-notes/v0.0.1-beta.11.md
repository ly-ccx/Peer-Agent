## 新功能

- 工作台 diff 视图支持解析并打开跨仓库文件路径，聊天里的文件路径链接可直接点击跳转。
- 模型配置支持「复制」：可基于已有非订阅 provider 快速复制一份配置（订阅类型除外）。
- Anthropic xhigh 推理档忠实映射到原生 `output_config.effort=xhigh`，不再折叠到 high。

## 优化

- 右侧工作台默认宽度从 420 调大到 600，信息展示更从容。
- 同会话内新建后续计划时也会自动展开工作台。
- 更新弹窗的吉祥物图标改为圆角。
- 清理上下文压缩中已失效的 `targetRatio` / `keepRecentCount` 死代码（不改变运行行为）。

## 修复

- 按文件是否真实存在来判定路径链接，不再把 git 分支名、`org/repo` 仓库名误判为可点击的本地文件路径。
- 修复目标计划面板的滚动问题：卡片不再被压缩，主体可正常滚动，进度条在主卡片正确显示。
