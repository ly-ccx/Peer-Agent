## 发布说明

- **0.1.0-rc.30** 在 RC29 上改进多任务阅读与输入体验，并修复机器人连续失败后的恢复阻塞。正式版仍为 0.0.18。

## 新功能与优化

- 网页、文件、变更与只读子 Agent 会话使用独立第四栏；机器人概况、任务、目标、记忆和设置可独立打开，切换资源保留会话现场。
- 已保存的 Bot 回复提供直接“引用”入口，继续支持选中文字引用；引用时保留输入草稿，显示来源并可返回原文。
- 将输入草稿更新限制在输入区，移除逐字输入时的同步高度测量，减少长会话与并行任务场景的输入开销。
- 下载进度圈在原点击范围内保持正圆，校准内环与数字尺寸。

## 修复

- 修复机器人处于连续失败暂停期时，新消息查询空任务 ID 导致 SQLite 报错并反复延长暂停时间。
- 修复恢复请求成功保存阶段进展后，试运行标记未释放，导致后续执行一直被阻止。
- 更新双语使用说明、README 与网站更新日志，说明第四栏和回复引用的入口。

## 升级与范围

- 升级前备份完整数据目录，Desktop、CLI/TUI 与 Gateway 应使用匹配版本。本版不引入新的数据格式；RC29 的监督记录读写版本限制继续有效，降级仍需升级前的完整备份。
- 未确认的执行结果继续保留为未知；恢复修复不意味着旧命令成功，也不会据此重放未知副作用。
- 发布操作不安装或重启当前应用。隔离回归与受控模型不能代替真实供应商质量、完整硬件输入法和读屏、各平台安装交互或长期使用验证。

## Release notes

- **0.1.0-rc.30** improves multitask reading and typing on RC29 and fixes blocked recovery after repeated Bot failures. Stable remains 0.0.18.

## What's new and improvements

- Open web pages, files, diffs and read-only child Agent conversations in an independent fourth pane. Bot overview, tasks, goals, memory and settings open separately, while resource switching preserves conversation state.
- Quote a saved Bot reply directly or keep quoting selected text. Preserve the current draft, show the source and navigate back to the original message.
- Keep draft updates within the composer and remove synchronous height measurement on every keystroke, reducing typing overhead in long conversations and parallel work.
- Keep the download progress ring circular within its existing hit target and adjust the inner ring and digits.

## Fixes

- Avoid querying SQLite with a missing work ID when new input arrives during a failure cooldown, preventing repeated errors from extending the pause.
- Release recovery admission after a successful slice saves its progress, allowing the following continuation to run.
- Update bilingual usage documentation, READMEs and the website changelog for the fourth pane and reply quoting.

## Upgrade and limits

- Back up the complete data directory and keep Desktop, CLI/TUI and Gateway on matching versions. This release adds no data format; RC29's supervision reader/writer restrictions still apply, and rollback requires the full pre-upgrade backup.
- Unconfirmed execution outcomes remain unknown. These recovery fixes do not certify old commands or replay unknown external effects.
- Publication does not install or restart your app. Isolated regression and controlled cognition do not establish real-provider quality, full hardware IME or screen-reader coverage, all platform installation interactions or long-duration acceptance.
