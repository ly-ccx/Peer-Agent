## 发布状态

- **0.1.0-rc.9** 打磨任务详情、历史对话、引用与全局界面一致性，供继续评测。正式版仍为 0.0.18；全面验收、连续七天日用和正式版批准仍按原计划执行。

## 任务与历史对话

- 任务详情先说明当前进展、下一步和需要回答的具体问题；内部派工指令、模型与标识按需展开。进展使用当前状态，已读取的报告保留供核对。
- 资料加载、读取失败和旧报告有明确说明及重试入口。关闭嵌套详情后保留原任务，询问进展时先准备主对话草稿，已有正文和附件继续保留。
- 历史对话按时间分组，支持搜索、预览和交给机器人继续。任务展开收起使用统一过渡，保留键盘操作、焦点返回及减少动态效果设置。

## 引用与界面

- 回复引用融入消息气泡顶部，用较小的来源文字与摘要表达层级；短引用不再独立形成小方块卡片，没有装饰竖线。选中文字的引用按钮继续靠近选区，保留定位原消息与草稿。
- 统一控件、列表、面板、弹窗、消息和输入框的圆角规则。主题预览和非正方形图片保持圆角矩形，数量标签使用胶囊圆角，头像和圆形按钮保留圆形。
- 加载、展开、返回、关闭及重命名提示使用 SVG 图标；原生选择器保留原有交互。修复键盘展开诊断信息时整页被卷走、顶部裁切的问题。
- 扩充界面规则检查与宽窄窗口、深浅主题的产品回归，覆盖真实矩形本地图片、灯箱键盘操作、引用、任务资料失败恢复及历史交互。

## 升级与回退

- 退出旧宿主，备份完整数据根，Desktop、CLI/TUI 与 Gateway 同步升级。npm 固定版本为 `@peer-agent/cli@0.1.0-rc.9`，`@rc` 跟随后续候选；归档中的 peer 与凭据助手须保持同目录。

## Release status

- **0.1.0-rc.9** refines task details, conversation history, quotations and interface consistency for continued evaluation. Stable remains 0.0.18; comprehensive acceptance, seven days of daily use and stable-release approval remain required.

## Tasks and conversation history

- Task details lead with current progress, the next step and any concrete question. Dispatch instructions, model information and internal identifiers are available on demand. Current state takes priority while retrieved reports remain available for inspection.
- Loading, failed reads and retained reports have clear explanations and retry actions. Closing nested details retains the task. Asking for progress prepares a main-conversation draft while preserving existing text and attachments.
- Conversation history groups entries by time and supports search, preview and continuation with a bot. Task disclosures share consistent transitions while retaining keyboard access, focus return and reduced-motion preferences.

## Quotations and interface

- Reply quotations sit inside the message bubble above its body, using smaller source text and a compact summary. Short quotations no longer form separate small cards, and there is no decorative vertical rule. Selection actions stay near the selected text and preserve source navigation and drafts.
- Controls, rows, panels, dialogs, messages and composers share semantic corner-radius rules. Theme previews and rectangular images remain rounded rectangles; count badges use pill corners, while avatars and circular buttons retain their shape.
- Loading, disclosure, return, close and rename indicators use SVG icons. Native selectors retain their interaction. Fix keyboard focus on diagnostic disclosures scrolling the outer application container and clipping its header.
- Extend interface convention checks and product regression across wide and narrow windows and both themes, including real rectangular local images, keyboard image previews, quotations, task-report recovery and history interactions.

## Upgrade and rollback

- RC4–RC8 can check for RC9 through Auto or Beta in Settings → Update & About. Older Beta5/RC1–RC3 require a manual installer matching their architecture.
- Quit older hosts, back up the complete data root and upgrade Desktop, CLI/TUI and Gateway together. Use `@peer-agent/cli@0.1.0-rc.9` for a fixed npm version; `@rc` follows later candidates. Keep peer and its credential helper together.
- Do not let an older version write directly to a data directory used by the new version. Roll back using the complete pre-upgrade backup while retaining new data and artifacts separately. Upgrading does not require a data reset.

## Validation and known limits

- Source product regression includes 95 required screenshots and deterministic interaction checks. Screenshots are inspected by the implementer, not an independent reviewer. Scripted cognition reproduces interface states and does not establish live model quality or network behavior.
- Release checks cover desktop artifacts for three platforms, CLI archives for two platforms, update manifests and macOS signing and notarization. Interactive Windows/Linux installation, full screen-reader testing, native translucent appearance and long-term use still require their corresponding acceptance. Some legacy artifact and Diff screenshots use isolated production-component fixtures.
- This release does not move execution, authorization or storage boundaries. Recorded subscription failures, some response timeouts, complex-write Evidence completeness and verifier independence across providers remain coverage gaps. Overall readiness and GA are not declared complete.
