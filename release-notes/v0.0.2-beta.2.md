## 说明

- **0.0.2-beta.2** 是 0.0.2-beta.1 之后的桌面体验修复版，聚焦输入框附件布局、操作栏间距，以及模型级联菜单定位。
- 本版不改变本地能力执行、显式授权与 Evidence 边界。

## 修复

- **输入框附件遮挡文字**：粘贴图片后缩略图不再与草稿文字叠放；附件条独占输入框顶部独立一排，无附件时不占额外高度。
- **输入框操作栏留白**：收紧首页 / 会话输入框底部与左右内边距，让 `+`、模型选择与发送按钮更贴近边框。
- **模型级联子菜单对齐**：二级模型菜单对齐到当前一级 Provider 行，而不是从列表顶部开始下排，减少选歪。

## CLI（仅命令行）

- 本版 GitHub Release 附带 CLI 归档（与 Desktop 同 tag / 同版本）。
- 资产示例：`peer-darwin-arm64.tar.gz`（内含 `peer` + `peer-credential-helper`，**必须同目录**）。
- 安装方式：
  - **npm（有 `NPM_TOKEN` 且 publish 成功时）**：`npm i -g @peer-agent/cli@beta`（或 `pnpm add -g @peer-agent/cli@beta`），`postinstall` 自动拉本版归档。
  - **手动**：解压归档后将目录加入 `PATH`，执行 `peer --version` 校验，再运行 `peer`。
- 可不装 Desktop；会话与设置仍落在 `~/.peer-agent`，与客户端共享。

locale:en-US

## Notes

- **0.0.2-beta.2** is a Desktop polish release after 0.0.2-beta.1, focused on composer attachment layout, action-bar spacing, and cascading model-menu placement.
- Local capability execution, explicit authorization, and Evidence remain unchanged.

## Fixes

- **Composer attachment overlay**: pasted image thumbnails no longer cover draft text; attachments occupy a dedicated top row and collapse when empty.
- **Composer action-bar padding**: tighter bottom and side padding on home/session composers so the attach, model, and send controls sit closer to the edge.
- **Cascading model submenu alignment**: secondary model menus open aligned to the current provider row instead of stacking from the first item, reducing mis-selection.

## CLI (command-line only)

- This GitHub Release also ships CLI archives (same tag / version as Desktop).
- Asset example: `peer-darwin-arm64.tar.gz` (contains `peer` + `peer-credential-helper`; **must stay side-by-side**).
- Install:
  - **npm (when `NPM_TOKEN` is present and publish succeeds)**: `npm i -g @peer-agent/cli@beta` (or `pnpm add -g @peer-agent/cli@beta`); `postinstall` fetches this version's archive.
  - **Manual**: unpack the archive, add the directory to `PATH`, verify with `peer --version`, then run `peer`.
- Desktop is optional; sessions and settings still live under `~/.peer-agent` and are shared with the app.
