## 新功能

- **新增 Qoder 模型供应商**：可接入 Qoder 私有供应商，模型目录在聊天菜单里展开为「供应商 → 模型」的悬浮父子菜单，未配置密钥的模型自动置灰；设置页的模型增删改不受影响。
- **模型与思考模式随会话绑定并持久化**：每个会话各自记住所选模型与思考强度，切换会话或重启后自动恢复；首选模型失效时回退到默认，不会中断对话。

## 优化

- 处理「安装 / 配置 / 管理 MCP」类请求更准确：助手会优先识别自己就是 MCP host 并查看自身注册表，而不是先去扫描外部客户端配置。

## 修复

- 修复连接在传输中途恢复时，「正在重试连接」横幅一直残留不消失的问题。
- 修复 Goal 模式下纯问答结束后，仍残留「执行中 0/1」目标契约的问题。
- 修复侧边栏删除确认的冗余「确认？」文字，并修正确认按钮垂直错位。
