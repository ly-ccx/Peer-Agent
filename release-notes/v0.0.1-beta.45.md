## 说明

- 本版在 **0.0.1-beta.44** 之上，聚焦 **流式卡顿与 Goal 面板性能**、聊天长列表虚拟化、托盘最近会话可用性，以及 Browser / 上下文压缩 / 提供商重试稳定性。
- 若你在 beta.44 上遇到流式输出时计划面板卡顿、侧栏右键菜单被遮挡，或托盘「更多」打不开更多会话，请直接升级本版。

## 新功能

- **Goal 运行计时**：计划执行中展示活跃运行时长，便于判断任务是否卡死。
- **Goal 持久化检查点**：执行链路补齐 checkpoint / 幂等与压缩后续处理，降低中断后状态丢失风险。
- **聊天虚拟列表与后台流缓冲**：抽出 VirtualChatTurnList，后台会话流式补丁合并，减少非当前会话对主列表的冲击。
- **Browser 能力增强**：Browser 溢出菜单 P0、密码管理器 Phase 1、可从 Chrome 导入站点会话 Cookie；Files 树支持刷新与轻量监听。
- **Qoder 额度展示**：设置与上下文环展示 Qoder 积分、折扣与额度信息。
- **GPT 推理分层**：拆分 reasoning summary 与 reasoning text；暴露 GPT-5.6 思考档位。
- **TUI**：展示 prompt cache 命中率。

## 优化

- **流式时 PlanCard 不再被打穿 memo**：`InteractionContext` 拆成稳定 actions 与 streaming 状态，`selectInteractionOption` 身份跨流式帧保持稳定。
- **Goal 进度 IPC 合并**：soft progress 广播 100ms 合并；runner 双通道等价快照去重；Qoder catalog 本地读盘 5s 短缓存。
- **GoalPlanPanel 视图模型 memo**：active/main/list 与父子关系缓存，减少无意义重渲染。
- **输入与附件热路径**：composer 用 CSS `field-sizing` 自适应高度；历史附件图片延迟加载/解码。
- **Frost 玻璃视觉**：浮层、侧栏选中态、Goal / Quick Chat / Skills 表面与毛玻璃 token 对齐。
- **上下文压缩**：语义化压缩与预算安全；provider usage 在观察时持久化快照。

## 修复

- **托盘「更多」**：改为原生二级菜单展示第 6–20 条最近会话；不再只打开主窗口，也不再把列表硬钳在 5 条。
- **侧栏右键菜单**：改为 portal 并夹紧到视口，避免被遮挡。
- **流式 stick-to-bottom**：跳到最新后继续流式时保持贴底。
- **提供商重试**：ChatGPT overload / server_error 自动重试；Qoder 队列与重复流错误自动重试。
- **recovering-fetch**：连接重试时用 `buildInit` 重建 RequestInit，避免复用已消费 body。
- **附件文案**：澄清「不支持」提示，反映 Agent 仍可读取本地文件。
- **GPT 订阅上下文窗口**：恢复到 258k；默认不再强行请求 reasoning summary。
- **Browser 就绪**：等待可见 Browser 就绪后再操作。
- **其他**：侧栏运行中状态点 ripple、工作区选择器 hover 圆角、thinking 状态短语粘连、文档深色主题等。

## Notes

- Built on **0.0.1-beta.44**. Focus: **streaming/Goal panel jank**, virtualized chat list, tray recent-session usability, plus Browser/context-compaction/provider retry stability.
- Upgrade if beta.44 felt sticky during streaming with the plan panel open, sidebar context menus were clipped, or tray **More** did not show more chats.

## What's New

- **Goal runtime timing**: Show active runtime duration while a plan executes.
- **Goal durable checkpoints**: Checkpoint/idempotency and compaction follow-ups to reduce state loss after interruption.
- **Virtual chat turns + background stream buffer**: Extracted VirtualChatTurnList; coalesce inactive-conversation stream patches.
- **Browser enhancements**: Browser overflow menu P0, password manager Phase 1, import site cookies from Chrome; Files tree refresh/light watch.
- **Qoder quota UI**: Credits, discounts, and quota in settings and the context ring.
- **GPT reasoning split**: Separate reasoning summary from reasoning text; surface GPT-5.6 reasoning tiers.
- **TUI**: Prompt cache hit rate display.

## Improvements

- **PlanCard memo survives stream frames**: Split InteractionContext into stable actions vs streaming state; keep `selectInteractionOption` identity stable across tokens.
- **Coalesced Goal progress IPC**: Soft progress notify at 100ms; dedupe dual-channel runner snapshots; 5s TTL cache for local Qoder catalog reads.
- **Memoized GoalPlanPanel view model**: Cache active/main/list selection and parent/child relations.
- **Composer/attachment hot path**: CSS `field-sizing` autosize; defer historical attachment image load/decode.
- **Frost glass polish**: Floating panels, selected sidebar row, Goal/Quick Chat/Skills surfaces.
- **Context compaction**: More semantic, budget-safe compaction; persist provider_usage snapshots at observe time.

## Fixes

- **Tray More**: Native submenu for conversations 6–20; no longer only opens the app or hard-clamps to 5.
- **Sidebar context menu**: Portal + viewport clamp so the menu is not covered.
- **Stick-to-bottom while streaming**: Stays pinned after jump-to-latest during continued streaming.
- **Provider retries**: Auto-retry ChatGPT overload/server_error; auto-retry Qoder queue/duplicate stream errors.
- **recovering-fetch**: Rebuild RequestInit via `buildInit` on connection retries.
- **Attachment copy**: Clarify unsupported messaging while agents can still read local files.
- **GPT subscription context window**: Restored to 258k; stop requesting reasoning summary by default.
- **Browser readiness**: Wait for the visible browser to be ready.
- **Other**: Running sidebar status-dot ripple, workspace selector hover radius, thinking status phrase gluing, docs dark theme, etc.
