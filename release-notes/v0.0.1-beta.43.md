## 说明

- 本版包含 **0.0.1-beta.42** 的全部用户可见更新，并修复 beta.42 因 macOS 打包失败而未正式发布的问题。
- 若你未成功装上 beta.42，请直接使用本版。

## 新功能

- **CLI 固定用户上下文条**：会话区上方固定显示当前相关的用户消息；运行中跟本轮提问，回看时尽量跟随视口对应的提问。
- **CLI 订阅额度**：会话顶栏在订阅账号下显示额度信息，并与在线状态右对齐排布。
- **CLI 霓虹活动态**：运行中状态有更清晰的霓虹活动反馈，并支持天/时/分的耗时展示。
- **CLI 模型能力**：模型列表支持一键复制整行配置；顶栏显示模型 · 思考力度，并修正 Grok 默认思考级别。
- **CLI 新会话与快捷键**：新增 `/new` 开启空会话，支持 Ctrl+X 组合快捷键。
- **CLI 历史窗口**：对话渲染改为有界窗口，默认从最近压缩点连续展示到现在；`/history` 统一浏览压缩前归档。
- **CLI 代码高亮**：围栏代码块增加轻量语法高亮。
- **CLI Grok 登录续期**：遇到 `scope_upgrade_required` 时自动触发重新登录，且登录提示不再挡住输入框。
- **上下文与压缩统一**：Desktop / CLI 共享压缩进度估算、连续性 handoff 与 provider 用量口径，减少两端行为分叉。

## 优化

- **Desktop 输入框浮起阴影**：聊天输入框四周增加轻微阴影，更有浮起层次。
- **Desktop 上下文展示**：隐藏用户不需要的内部 pending 细节，界面更干净。
- **CLI 压缩与历史**：压缩摘要输入预算与 Desktop 对齐；COMPACTED 行显示真实压缩方法；状态栏用单条紧凑进度条。
- **CLI 输入体验**：软换行、按实际折行增高输入框、Shift+Enter 换行；粘贴图片不再重复内容或嵌套破损 chip。
- **CLI 主题与配色**：跟随系统自动切换浅色/深色；composer 颜色实时同步；活动色与 crush 渐变更一致。
- **CLI 工具与 Goal**：工具名间距更紧凑；Goal Runner 内部 tick 不再刷进聊天；新建 Goal 立即显示最新任务。
- **上下文占用**：发送后不再错误塌成 0%；按「下一请求」预算投影占用，Desktop / CLI 口径对齐。
- **网络恢复**：CLI 在流中断、网络抖动后可恢复 provider 连接，减少半截会话。

## 修复

- **macOS 打包失败**：修复 `app.asar` 误排除 `@peer-agent/system-context` 运行时入口（`src/index.mjs`），使 `Verify packaged runtime entries` 通过（本版热修）。
- **上下文回跳**：修复恢复投影低估导致发送后占用从约 4% 跳到 18% 等问题。
- **压缩与摘要**：修复中途自动压缩与 Desktop LLM 摘要不一致、压缩进度/连续性丢失等问题。
- **历史分页**：修复 earlier 历史卡死、分页边界不正确等问题。
- **Goal 绑定**：Goal Runner 绑定到所属会话，避免串会话；runner 停止时叶子任务正确标失败。
- **Provider 路由**：Anthropic 走 messages 协议，补齐 channel→wire 矩阵与 Gemini generateContent 路径；OpenAI 侧清理非法 function 名。
- **其他**：更新图标在有可用更新时正确显示；多处 Thinking / Markdown / 表格渲染边界修复。

## CLI / npm

- 本版 GitHub Release 继续附带 CLI 归档（与 Desktop 同 tag）：`peer-darwin-arm64.tar.gz`。
- 可安装：`npm i -g @peer-agent/cli@beta`。
- 安装后执行 `peer --version` 应输出 `peer 0.0.1-beta.43`。
- 会话与设置仍落在 `~/.peer-agent`，与 Desktop 共享。

## Notes

- This release includes all user-visible updates from **0.0.1-beta.42**, and fixes the macOS packaging failure that blocked a formal beta.42 release.
- If you never successfully installed beta.42, use this build directly.

## What's New

- **CLI pinned user context bar**: Keeps the relevant user message fixed above the session; follows the active turn while running, and tracks the in-view question when scrolling history.
- **CLI subscription quota**: Shows quota in the session header for subscription accounts, right-aligned with the online status.
- **CLI neon activity state**: Clearer neon activity feedback while running, with day/hour/minute duration display.
- **CLI model capabilities**: One-click copy of a full model row; header shows model · thinking strength; fixes the default Grok thinking level.
- **CLI new session & shortcuts**: Add `/new` for an empty session, plus Ctrl+X chord shortcuts.
- **CLI history window**: Bounded conversation rendering from the latest compact point to now; `/history` browses pre-compact archives.
- **CLI code highlighting**: Lightweight syntax highlighting for fenced code blocks.
- **CLI Grok re-auth**: Auto re-login on `scope_upgrade_required`, and login prompts no longer block the input box.
- **Shared context & compaction**: Desktop / CLI share compact progress estimates, continuity handoff, and provider usage accounting.

## Improvements

- **Desktop composer shadow**: Subtle elevation shadow around the chat input.
- **Desktop context UI**: Hides internal pending details users do not need.
- **CLI compact & history**: Aligns compact input budget with Desktop; COMPACTED rows show the real method; status bar uses a single compact progress bar.
- **CLI input UX**: Soft wrap, auto-grow by wrapped lines, Shift+Enter newline; image paste no longer duplicates content or nests broken chips.
- **CLI theme & colors**: Follows system light/dark; composer colors stay in sync; activity colors match the crush gradient more closely.
- **CLI tools & Goal**: Tighter tool-name spacing; Goal Runner internal ticks no longer flood chat; new Goals show latest tasks immediately.
- **Context occupancy**: No longer collapses to 0% after send; projects occupancy from the next-request budget on Desktop and CLI.
- **Network recovery**: CLI can restore the provider connection after stream drops / network blips.

## Fixes

- **macOS packaging**: Stop excluding `@peer-agent/system-context` runtime entry (`src/index.mjs`) from `app.asar` so packaged runtime verification passes (hotfix).
- **Context jump**: Fix restore projection under-estimates that made occupancy jump from ~4% to 18% after send.
- **Compaction & summaries**: Align mid-run auto-compact with Desktop LLM summaries; restore compact progress / continuity.
- **History paging**: Fix stuck earlier-history and incorrect page boundaries.
- **Goal binding**: Bind Goal Runner to its owning session; mark leaf tasks failed when the runner stops.
- **Provider routing**: Anthropic via messages protocol, channel→wire matrix + Gemini generateContent path; strip illegal OpenAI function names.
- **Other**: Update badge shows correctly when an update is available; Thinking / Markdown / table rendering edge cases.

## CLI / npm

- This GitHub Release still ships the CLI archive under the same Desktop tag: `peer-darwin-arm64.tar.gz`.
- Install: `npm i -g @peer-agent/cli@beta`.
- After install, `peer --version` should print `peer 0.0.1-beta.43`.
- Sessions and settings still live under `~/.peer-agent` and are shared with Desktop.
