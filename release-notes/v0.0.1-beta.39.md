## 新功能

- **`@peer-agent/cli` npm 安装器**：可通过 npm 安装 CLI 包装包；postinstall 从同版本 GitHub Release 拉取平台 `peer` 二进制与 credential helper。
- **Goal 与 Desktop 共享**：TUI Goal 直接使用 Desktop 的 goal-plan-store；Goal 模式强化 intake，打包 CLI 可嵌入 goal store。
- **Frost 主题**：TUI 新增 Frost light/dark，wordmark 随主题变化。
- **上下文压力与自动压缩**：TUI 与 Desktop 对齐上下文压力展示；发送时按预算自动 compact，并增强压缩可恢复性。
- **任务完成提醒**：系统通知 + 侧栏未读绿点，任务结束后更易察觉。
- **Composer 运行态**：页脚运行中 spinner、思考状态停靠在输入区上方，与 mode 控件分层更清晰。
- **中文与交互打磨**：中文文案、图片 chips、圆角菜单、队列/侧栏/用量/重试倒计时等体验优化。

## 优化

- 思考与工具段按事件序交错展示；流结束后自动收起 process 面板。
- 工具调用持久化与 Desktop 对齐，流失败可恢复；工具 running 状态更稳定。
- 模型推理 effort 与 Desktop 对齐；无可用档位时隐藏 effort 控件。
- 上下文环与 compaction 预算一致；mode 分割线全宽、空闲时隐藏。
- 更新弹窗改为 changelog 卡片；去掉多余「更新就绪」toast。
- CLI 内容增加外边距，避免贴边；Workbench 顶栏间隙收紧。

## 修复

- 打包 CLI 静态导入 goal-plan-store，避免运行时路径查找失败。
- 思考状态改用 leading spinner；思考渲染进消息时间线，粘贴草稿不丢。
- 图片路径粘连提取与 Desktop 附件持久化；发送后历史里正确显示图片 chips。
- 回复结束后保持所选模型；恢复会话选择后关闭 resume picker。
- 非法 tool-call JSON 参数可恢复；slash 建议忽略绝对路径。
- 不再硬拦截 workspace 外路径；用户态与思考态展示更顺。

## CLI / npm

- GitHub Release 继续附带 `peer-darwin-arm64.tar.gz`（与 Desktop 同 tag）。
- 本版起可安装：`npm i -g @peer-agent/cli@beta`（需仓库已配置 `NPM_TOKEN`；否则仅发 GitHub Release，可从 Release 资产手动装 CLI）。
- 安装后执行 `peer --version` 应输出 `peer 0.0.1-beta.39`。
- 会话与设置仍落在 `~/.peer-agent`，与 Desktop 共享。

## What's New

- **`@peer-agent/cli` npm installer**: Install a CLI wrapper via npm; postinstall pulls the platform `peer` binary and credential helper from the same-version GitHub Release.
- **Goal shared with Desktop**: TUI Goal uses Desktop’s goal-plan-store directly; Goal mode strengthens intake; packaged CLI can embed the goal store.
- **Frost theme**: TUI adds Frost light/dark; wordmark follows the theme.
- **Context pressure & auto-compact**: TUI aligns context-pressure display with Desktop; auto-compact on send by budget, with stronger recoverability.
- **Task completion reminders**: System notifications plus unread green dots in the sidebar after tasks finish.
- **Composer running state**: Footer running spinner and thinking state dock above the input, layered more clearly with mode controls.
- **Chinese & interaction polish**: Chinese copy, image chips, rounded menus, queue/sidebar/usage/retry countdown UX.

## Improvements

- Thinking and tool segments interleave by event order; process panel auto-collapses after stream end.
- Tool-call persistence aligns with Desktop; recoverable after stream failure; running tool state is stabler.
- Model reasoning effort aligns with Desktop; hide the effort control when no levels are available.
- Context ring matches compaction budget; mode divider is full width and hidden when idle.
- Update modal becomes a changelog card; remove the extra “update ready” toast.
- CLI content gains outer margin so it is not flush to edges; Workbench top-bar gap tightens.

## Fixes

- Packaged CLI statically imports goal-plan-store so runtime path lookup does not fail.
- Thinking state uses a leading spinner; thinking renders into the message timeline; paste drafts are kept.
- Sticky image-path extraction and Desktop attachment persistence; image chips show correctly in history after send.
- Keep the selected model after a reply ends; close the resume picker after restoring a session selection.
- Recoverable illegal tool-call JSON args; slash suggestions ignore absolute paths.
- No longer hard-block paths outside the workspace; user-state and thinking-state display feel smoother.

## CLI / npm

- GitHub Release still ships `peer-darwin-arm64.tar.gz` (same tag as Desktop).
- From this release you can install: `npm i -g @peer-agent/cli@beta` (requires `NPM_TOKEN` in the repo; otherwise only the GitHub Release is published and you can install CLI from Release assets manually).
- After install, `peer --version` should print `peer 0.0.1-beta.39`.
- Sessions and settings still live under `~/.peer-agent` and are shared with Desktop.
