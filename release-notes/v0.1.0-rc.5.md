## 发布状态

- **0.1.0-rc.5** 是供负责人详细评测的修复候选版。正式版仍为0.0.18，npm beta仍为0.1.0-beta.5；全面测试、连续七天日用及明确批准后才发布正式0.1.0。
- 保留此前候选的机器人、任务、目标、记忆、TUI、远程、更新与诊断功能。现存核验缺口仍列为未Ready，不把候选发布当成全部验收通过。

## 本次修复

- 去掉对话消息和输入区域的光晕，整理深浅色表面与主题颜色。
- 回复引用改为可点击的上下文块，可以定位原消息；取消左侧强调线，保留均匀边框和背景。
- 整理“查看过程”、记忆和引用操作，使用SVG图标及清晰的按钮反馈；窄窗口与键盘操作保留，取消输入引用不会丢掉草稿。
- 机器人档案 → 设置的首屏增加明确的“机器人模型”区域：分别选择对话模型、任务执行和复核模型，或跟随全局。每个Bot独立自动保存，重新打开仍保留。对话模型用于后续回复，任务模型用于新任务；不会改变其他Bot或全局路由。

- 详细步骤见[全面测试手册](https://github.com/ly-ccx/Peer-Knowledge/blob/PeerKnowledge/pa/rc-05-docs/playbook/v0.1.0/acceptance-test-guide.md)，自测范围见[开发者报告](https://github.com/ly-ccx/Peer-Knowledge/blob/PeerKnowledge/pa/rc-05-docs/playbook/v0.1.0/rc-self-test-report.md)。手册与报告中的实际结果为准，预期行为不等于已验通过。

## Release status

- **0.1.0-rc.5** is a repair candidate for detailed owner evaluation. Stable remains 0.0.18 and npm beta remains 0.1.0-beta.5. Version 0.1.0 requires comprehensive testing, seven days of daily use and explicit approval.
- Bots, tasks, objectives, memory, TUI, remote input, updates and diagnostics remain available. The existing verification gap remains not ready; publishing this candidate does not establish overall acceptance.

## Fixes

- Remove the glow around conversation messages and the composer; refine light/dark surfaces and theme colors.
- Make reply context a clickable block that locates the original message. Remove the left accent while retaining a uniform border and background.
- Refine process, memory and quote controls with SVG icons and clear button feedback. Keep keyboard and narrow-window access; cancelling a quote preserves the draft.
- Put explicit Bot models at the top of Profile → Settings. Choose separate conversation, execution and verification models, or inherit global routing. Each bot saves independently and retains the selection after reopening. Conversation changes apply to future replies; task changes apply to new tasks. Other bots and global routing remain unchanged.

## Upgrade and evaluation

- RC4 users can check for RC5 through Auto or Beta in Settings → Update & About, or download the matching installer here. Older Beta5/RC1–3 updaters have known release-selection errors and require a manual upgrade; decline older Beta downgrade prompts.
- Quit older hosts, back up the complete data root and upgrade Desktop, CLI/TUI and Gateway together. Bot identities, conversations, avatars, model preferences, objectives and memory remain; no reset is required. Settings → General → Interface restores classic chat.
- The macOS CLI archive includes the signed credential helper from the same Desktop build. Keep peer and peer-credential-helper together. Install the fixed npm version with `@peer-agent/cli@0.1.0-rc.5`; `@rc` follows future candidates. Record the actual version and installer SHA.
- Follow the [comprehensive test guide](https://github.com/ly-ccx/Peer-Knowledge/blob/PeerKnowledge/pa/rc-05-docs/playbook/v0.1.0/acceptance-test-guide.md) and [developer report](https://github.com/ly-ccx/Peer-Knowledge/blob/PeerKnowledge/pa/rc-05-docs/playbook/v0.1.0/rc-self-test-report.md). Their recorded results define the tested scope; expected behavior is not a passing result.

## Validation and known limits

- Full local candidate gates, 23 controlled upgrade rows, both CI platforms and isolated native windows have separate evidence. Source acceptance covers model persistence/inheritance/isolation, reply controls, themes, narrow drawers, performance budgets and update layouts. Signed-package, live network and installation results are recorded separately.
- Independent verification of complex writes may still reject results because executed-command descriptors are incomplete in the Evidence snapshot. Rejection remains enforced. Correct files or an assistant completion claim do not establish verification or acceptance. This still blocks overall readiness and GA.
- Interactive Windows/Linux installation, physical phones, production OIDC/remote deployments and seven-day use require their corresponding environments. Remote input is text only with the computer online and approvals local. Isolated writes require Git; external side effects need authorization. Objective token hard limits remain rejected. Uploaded avatars are static; default SVG avatars animate by state.
