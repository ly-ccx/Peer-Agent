## 说明

- **Peer Agent 0.0.4-beta.3** 让 Goal 在隔离工作树里落地，验收后再合回，并补上交付路由与质检闭环。
- 同时开放 Grok Fast / xhigh，并把侧边栏从“关闭工作区”改成项目文件夹入口。
- 文档站 Changelog 已同步本版说明。

## 新功能

- **Goal 隔离落地**：绑定仓库的 Goal 在独立 Git worktree 中执行；验收后可把隔离改动合回原工作区，并显示交付交接状态。
- **交付路由与质检**：按交付类型走不同落地路径，并在查看结果后再进入质检循环。
- **Grok Fast / xhigh**：Grok 支持 Fast 模式，以及更高的 xhigh 推理强度。
- **项目文件夹**：侧边栏改为打开项目文件夹，不再用关闭工作区替代本地目录入口。
- **结果抽屉滚动**：结果抽屉增加滚动按钮，长结果更容易回到当前阅读位置。

## 优化

- **品牌刷新**：更新应用与文档站品牌资源，侧边栏字标缩短为 Peer。
- **工作台更干净**：去掉结果抽屉副标题，把首页卡片运行信息收到操作行，锁定聊天顶栏高度，并压低验收碎裂粒子数量。
- **Goal 卡片更紧凑**：压缩 Goal 进展展示，并让抽屉工作台与主工作台互不抢状态。

## 修复

- 修复文件搜索未中止、首页过期 hydrate 仍刷新的问题。
- 修复 Goal 验收后不启动首轮、同会话新 Goal 覆盖旧计划、以及未验收计划被后续任务清掉的问题。
- 修复 worktree 消失仍报清理失败、清理前未收集改动、以及前台 runner 状态不同步的问题。
- 修复结果抽屉在验收碎裂前未关闭、项目文件夹右键打不开、以及 Grok xhigh 被旧缓存盖住的问题。
- 修复 Markdown 链接、决策箭头和讨论总数显示。

## CLI（仅命令行）

- 安装：`npm i -g @peer-agent/cli@beta`（或 `pnpm add -g @peer-agent/cli@beta`）；`postinstall` 会下载本版归档。
- 也可手动解压归档，把目录加入 `PATH`，先运行 `peer --version`，再运行 `peer`。
- CLI 与 Desktop 继续共享 `~/.peer-agent` 下的会话和设置。

## Notes

- **Peer Agent 0.0.4-beta.3** runs bound Goals in an isolated worktree, lands those changes after acceptance, and closes the delivery-routing plus quality-review loop.
- It also exposes Grok Fast / xhigh and replaces workspace-close with project folders.
- The docs changelog now includes this release.

## What's New

- **Isolated Goal landing**: bound Goals run in a dedicated Git worktree; accepted changes can land back into the original workspace, with a visible delivery handoff status.
- **Delivery routing and quality loop**: route landings by delivery type, then start quality review after the result is viewed.
- **Grok Fast / xhigh**: Grok now has a Fast mode and a higher xhigh reasoning effort.
- **Project folders**: the sidebar opens project folders instead of closing the workspace.
- **Result-drawer scroll**: a scroll button makes long result drawers easier to navigate.

## Improvements

- **Brand refresh**: update app and docs brand assets, and shorten the sidebar wordmark to Peer.
- **Cleaner workbench**: drop the result-drawer subtitle, move home-card runtime meta onto the action row, lock the chat header height, and cap acceptance shatter particles.
- **Tighter Goal cards**: keep Goal progress compact and isolate the drawer workbench from the main one.

## Fixes

- Abort in-flight file search and skip stale home hydrates.
- Start the first runner turn after intake handoff, keep the old plan when a new Goal starts in the same conversation, and preserve unaccepted plans across follow-ups.
- Treat vanished worktrees as already cleaned, collect worktree changes before cleanup, and reconcile foreground runner state.
- Close the result drawer before card shatter, open project folders from the workspace context menu, and keep Grok xhigh above a stale effort cache.
- Render markdown links, draw the decision arrow as SVG, and show the total discussion count.

## CLI (command-line only)

- Install with `npm i -g @peer-agent/cli@beta` (or `pnpm add -g @peer-agent/cli@beta`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
