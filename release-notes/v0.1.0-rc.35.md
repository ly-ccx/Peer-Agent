## 发布说明

- **0.1.0-rc.35** 补修 RC34 遗留的任务排队自阻塞：成功派发后留下的旧资源保护，经原始回执核对和停止屏障结清后，允许原任务继续。正式版仍为 0.0.18。

## 修复

- 恢复时先核对登记的派发 Evidence、完整 Tool Result 和已完成协调操作；即使父执行记录已退役，也能准确识别仍挂在原子任务上的旧资源记录。
- 尚未启动过的排队任务仅在身份、目标版本和执行代次匹配，且执行器、调度器与受管句柄均确认空闲后，通过现有停止屏障结清自身保护，再走正常调度。保留原任务、历史和预算，不重放调用。
- 活跃父协调调用不再被误算为子任务的未知执行；实际子执行及其他未知写入仍保留各自范围的保护。
- Desktop 与 CLI/TUI 使用同一恢复路径。沿用 RC34 的精简任务详情与 GPT-6.1 Terra 目录。

## 升级与验证范围

- 延续联合协调格式 9。安装更新前保留完整数据备份；未知外部效果不会因为时间、发布或任务文本被自动清除。
- 真实队列恢复、完整发布检查及安装后原任务实际进展分别记录。源码用例或调度准入本身不代表任务已完成或用户已验收。

## Release notes

- **0.1.0-rc.35** repairs the queued-task self-blocking left in RC34. Reconcile the original completed delegation result and settle its stale resource hold through the existing stop barrier so the original task can proceed. Stable remains 0.0.18.

## Fixes

- Reconcile registered delegation Evidence, the complete canonical Tool Result and the completed coordination operation before queue recovery, including claims whose parent attempt has already retired.
- Settle a never-started queued task's own protection only when task identity, goal revision and execution epoch match and the runner, scheduler and managed handles are confirmed idle. Resume normal scheduling with the original task, history and budget; never replay the call.
- Keep live parent coordination calls out of the child's unknown-execution set. Actual child execution and unrelated unknown writes retain their own scoped protection.
- Desktop and CLI/TUI share recovery. Retain RC34's compact task details and GPT-6.1 Terra catalog entry.

## Upgrade and validation scope

- Retain combined coordination format 9 and a complete pre-installation backup. Publication, time and task text cannot clear unknown external effects.
- Track real queue recovery, full release checks and installed original-task progress separately. Source tests and scheduler admission do not establish task completion or user acceptance.
