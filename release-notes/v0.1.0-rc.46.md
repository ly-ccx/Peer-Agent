## 说明

- 本版本让项目 Bot 的委派进度、结果核对和汇报状态更清晰，并改善后台任务的恢复、待处理输入和多 Bot 技能安装体验。

## 新增与改进

- **委派任务的实时计划**
  - 执行任务使用独立于主 Bot 对话的系统上下文。子任务可通过 `update_plan` 更新工作计划，工作区实时显示步骤进度、验收条件和执行约束。
- **工作现场和任务状态**
  - 工作现场以事项板取代「当前注意力」卡片，并新增可折叠的只读 Git 状态区，便于查看工作区变更。
  - 界面区分「正在核对结果」和「等待主 Bot 汇报结果」。子任务侧栏和工作区实时显示执行耗时，侧栏以流光猫头提示任务正在执行，并修正 macOS 窗口按钮对齐和侧栏折叠边距。
- **后台任务的恢复和流式反馈**
  - 临时推理错误可在当前步骤内自动重试，失败诊断按 ADR 139 脱敏。用户发送新消息时可优先于后台唤醒，子任务独立运行，宿主失败会显示在界面上。
  - 完善后台唤醒的投递结算，并恢复中断的结果核对。手动重试可接续已完成的工具调用和已保存的唤醒批次，主动让出执行的回合也可继续。无效的 Shell 超时参数现在会返回可恢复的错误。
  - 执行期间显示长度受限的工具输出预览，并实时呈现结构化回复草稿。实时图片授权会核对当前审批状态。
- **对话、待处理输入和附件**
  - 未认领的回执会显示在用户消息气泡上。待处理的消息可以放回输入框或丢弃，界面会明确显示已拒收的消息。排队的回答送达后会自动关闭对应待处理项，并清理重复的已关闭问题提示。
  - 恢复历史图片附件预览，统一嵌入式子任务对话区，并修复返回主对话时可能出现的白屏。系统会等子任务空闲后再同步模型推理深度，避免在查看运行中的子任务时触发设置写入错误。
- **技能安装、模型设置和输入建议**
  - 技能中心和已安装页统一按活跃 Bot 展示。安装技能时可多选 Bot，一次批量安装。
  - 恢复模型设置弹窗滚动，修正模型分工的路由参数和保存反馈，并调整 Tab 采纳建议的位置，避免遮挡输入框顶部的历史任务栏。

## Notes

- This release makes delegated work easier to follow from execution through verification and reporting. It also improves background recovery, pending messages, and skill installation across Bots.

## Highlights

- **Live plans for delegated tasks**
  - Delegated execution has its own system context, separate from the Main Bot conversation. Workers can update their plans with `update_plan`, and the task workspace shows live step progress, acceptance criteria, and execution constraints.
- **Work panel and task status**
  - The work panel uses a matter board in place of the Current Attention card. A collapsible, read-only Git section shows workspace changes.
  - The interface distinguishes active verification from waiting for the Main Bot to report. The task sidebar and workspace show live elapsed execution time, with an animated cat icon for running work. macOS window controls and collapsed sidebar spacing are aligned.
- **Background recovery and streaming feedback**
  - Transient inference failures can retry within the current step, and diagnostics redact sensitive details under ADR 139. New user messages take priority over background wakes, Workers run independently, and the interface surfaces host failures.
  - Background wakes track delivery through settlement, and interrupted verification can resume. A manual retry can resume from completed tool calls and saved wake batches, and turns can continue after yielding. Invalid shell timeouts return a recoverable error.
  - Activity shows bounded tool output previews and streams structured reply drafts as they are written. Live image grants check the current approval state.
- **Conversations, pending messages, and attachments**
  - User message bubbles show unclaimed receipts. Pending messages can be restored to the composer or discarded, with a distinct status for messages the Bot rejected. Queued answers close the associated attention item when delivered, and duplicate notices for closed questions are cleared.
  - Image previews work again in conversation history. Embedded Worker chats share a consistent layout, and returning to the Main Bot conversation restores its view. Model reasoning effort now syncs when the Worker is idle, preventing a settings write error when viewing a running task.
- **Skill installation, model settings, and input suggestions**
  - The Skills Center and Installed view both use the active Bot list. Select several Bots to install a skill in one operation.
  - The model settings dialog scrolls again, routing parameters and save feedback are consistent, and Tab-to-accept suggestions stay clear of the task history above the composer.
