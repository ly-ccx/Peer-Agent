locale:zh-CN

## 说明

- **Peer Agent 0.0.16** 聚焦桌面任务信息展示、模型目录与输入体验，并减少桌面预览证据查询的重复扫描。

## 优化

- 为订阅模型目录增加 GPT-6 Sol 和 Luna。
- 任务信息卡加入进出场动画，默认 Workbench 宽度收窄至 420px。
- 本地桌面预览截图目录加入 Git 忽略列表，避免将验收产物误提交。

## 修复

- 忙碌状态的英文输入框提示改为 “Type freely”，与中文“随心输入”保持一致；不改变发送逻辑。
- 桌面预览证据成员查询复用缓存，证据索引被外部改写后重新计算。

## CLI（仅命令行）

- CLI 与 Desktop 共用 0.0.16 版本号。本版 CLI 压缩包矩阵为 macOS ARM64、Linux x64；不提供 Windows CLI 压缩包，最终以 Release 资源为准。
- 请将压缩包中的 `peer` 与 `peer-credential-helper` 保存在同一目录。Desktop 提供 macOS、Windows 和 Linux 安装包。

locale:en-US

## Notes

- **Peer Agent 0.0.16** improves desktop task information, model selection, and composer copy while avoiding repeated scans for desktop preview evidence.

## Improvements

- Add GPT-6 Sol and Luna to the subscription model catalog.
- Animate the task information card on entry and exit, and narrow the default Workbench width to 420px.
- Ignore local desktop preview screenshots so acceptance artifacts are not accidentally committed.

## Fixes

- Replace the busy composer’s English placeholder with “Type freely” to match the Chinese “随心输入”; sending behavior is unchanged.
- Cache desktop preview evidence membership and recalculate it when the evidence index changes externally.

## CLI (command-line only)

- CLI and Desktop share version 0.0.16. CLI archives target macOS ARM64 and Linux x64; no Windows CLI archive is provided. Consult the actual Release assets for availability.
- Keep `peer` and `peer-credential-helper` in the same directory. Desktop installers are provided for macOS, Windows, and Linux.
