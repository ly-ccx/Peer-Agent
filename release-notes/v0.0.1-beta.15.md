## 新功能

- **左侧会话栏可自由调节**：拖动右边缘即可改变宽度，拖到足够窄会自动收起；主区顶栏左上角新增一个与右侧对称的开关按钮，一键展开/收起左栏，也支持 ⌘B 快捷键。
- **支持从 a1 公共仓借用技能**：通过软链接投影复用公共技能仓里的技能，无需重复安装。

## 优化

- 能力胶囊并入 MCP 工具列表并去除描边，能力区视觉更统一。
- 工作台打开时默认激活的标签由「终端」改为「目标」，更贴合常用流程。

## 修复

- 修复首个会话未使用「会话绑定的工作区根目录」的问题。
- 修复 MCP 工具偶发被误报为「不可用」的问题，并支持按服务折叠列表。
- 修复点击文件夹路径链接被误导入 Diff 视图的问题，现在按真实类型正确分流。
- MCP 刷新列表改为批量重新拉取清单，并补充刷新状态反馈。
- 修复历史压缩进度卡在 87% 后瞬跳完成的问题，收尾更平滑。
- 修复下载更新时左上角进度环被横条遮挡的问题，并强化更新弹窗的过渡动画。
