## 说明

- **Peer Agent 0.0.6** 把任务验收收成签字包：对照标准、仓库改动和剩余门槛，而不是执行日记。
- 新任务默认留在当前工作区，按需才隔离到 worktree，并在界面上显示已绑定的任务分支。
- 工作台改为左右分栏：左侧列表、右侧详情，两列可独立滚动。
- CLI 正式提供 Linux x64 归档；`peer exec` 会把本轮自己创建的 Goal 跑到终态。
- 文档站 Changelog 已同步本版说明。

## 新功能

- **验收签字包**：先看对照标准、仓库改动和还过不了的门槛；一键接受前必须能对上 Evidence。
- **任务分支**：写绑定的计划从工作区 base 拉出任务线，验收后再合回；默认不建 worktree。
- **按需隔离**：任务可选择在独立 worktree 执行，界面显示已绑定分支；升级隔离不会另开第二条分支。
- **工作台分栏**：首页左右分栏，列表与详情独立滚动，默认选中第一行。
- **上下文用量**：点击输入框占用环，查看按提供方口径拆开的请求构成。
- **无头浏览器**：浏览器面板关掉时，工具仍可在后台窗口执行。
- **Linux x64 CLI**：Release 提供 `peer-linux-x64.tar.gz`，npm 安装器会拉取对应归档。
- **`peer exec` Goal**：无头执行会把本轮新建的 Goal 推到终态，而不是停在「已接受 · 0/N」。

## 优化

- 侧栏会话行更紧，钉住图标与行的左内边距对齐。
- 思考中显示编织光球；右侧箭头只在悬停时出现。
- 工作台卡片按会话归组，并排任务不再互相挤位。
- 去掉 Desktop / TUI 里已过时的 Cloud CEO、Enterprise 文案。

## 修复

- 结果抽屉打开时不再把对话滚去聚焦某条消息。
- 已删除的工作区不会再出现在各处入口。
- 新任务会留在选定的工作区。
- Grok OAuth 读取共享凭证时不再丢掉 scope。
- 更新安装按钮在重复检查和休眠后仍可点。
- 错误边界的重载文案在深色主题下可读。
- Windows / Linux 不再预留下 macOS 红黄绿灯的空白。

## CLI（仅命令行）

- 本版 GitHub Release 附带 CLI 归档（与 Desktop 同 tag / 同版本）。
- 资产：`peer-darwin-arm64.tar.gz` / `peer-linux-x64.tar.gz`（内含 `peer` + `peer-credential-helper`，**必须同目录**）。
- 可通过 `npm i -g @peer-agent/cli@latest`（或 `pnpm add -g @peer-agent/cli@latest`）安装正式通道版本；`postinstall` 会拉取本版归档。
- 也可手动解压归档，将目录加入 `PATH`，执行 `peer --version` 校验后运行 `peer`。
- CLI 与 Desktop 继续共享 `~/.peer-agent` 下的会话和设置。

## Notes

- **Peer Agent 0.0.6** treats acceptance as a sign-off pack: criteria, repo changes, and remaining gates — not a runner diary.
- New tasks stay on the current workspace by default, isolate into a worktree only when you opt in, and show the bound task branch in the UI.
- The workbench is a split layout: list on the left, detail on the right, with independent column scrolling.
- CLI now ships a Linux x64 archive; `peer exec` drives Goal plans it created in that run to a terminal state.
- The docs changelog is in sync with this release.

## What's New

- **Acceptance sign-off pack**: show criteria, repo changes, and leftover gates; one-click accept requires resolvable Evidence.
- **Task branches**: write-bound plans fork a task line from the workspace base and merge back on accept; worktrees are off by default.
- **On-demand isolation**: a task can opt into a dedicated worktree, with the bound branch visible in the UI; upgrading isolation does not create a second branch.
- **Workbench split**: home uses list + detail columns that scroll independently, with the first row selected by default.
- **Context usage**: click the composer occupancy ring for a request-composition breakdown scaled to the provider.
- **Headless browser**: tools still run in a hidden window when the browser panel is closed.
- **Linux x64 CLI**: Releases include `peer-linux-x64.tar.gz`; the npm installer downloads the matching archive.
- **`peer exec` Goals**: headless exec drives plans created in that run to a terminal state instead of leaving them at accepted · 0/N.

## Improvements

- Sidebar conversation rows are denser, and the pin aligns with the row's left padding.
- Thinking shows the weaving orb; the trailing chevron appears on hover only.
- Workbench cards group by conversation and stay stable when several tasks run at once.
- Drop leftover Cloud CEO and Enterprise copy from Desktop and TUI.

## Fixes

- Opening the result drawer no longer scrolls the conversation to focus a message.
- Removed workspaces no longer resurface in other entry points.
- New tasks stay on the chosen workspace.
- Grok OAuth keeps its scope when reading shared credentials.
- The updater install button stays clickable across rechecks and sleep.
- Error-boundary reload text stays readable in dark theme.
- Windows / Linux no longer reserve space for macOS traffic lights.

## CLI (command-line only)

- This GitHub Release includes CLI archives (same tag / version as Desktop).
- Assets: `peer-darwin-arm64.tar.gz` / `peer-linux-x64.tar.gz` (contains `peer` + `peer-credential-helper`; **must stay in the same directory**).
- Install the stable channel with `npm i -g @peer-agent/cli@latest` (or `pnpm add -g @peer-agent/cli@latest`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
