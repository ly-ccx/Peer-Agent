## 发布状态

- **0.1.0-rc.17** 修复执行任务时的三处性能热点，以及子任务思考强度与机器人配置不一致的问题。正式版仍为 0.0.18，本版用于继续评测。

## 执行时的流畅度

- 读取任务进展时复用协调日志状态，只处理新追加的记录；文件替换、损坏和版本检查继续生效，长期历史不再被每次全量重放。
- 历史消息与机器人列表的头像保持静态，仅当前活动身份按状态显示动效，减少空闲绘制负担；减少动态效果设置继续有效。
- 大会话结束时，全文读取和序列化在后台 worker 中准备，主进程只完成短时间的校验与原子提交。回复完成、取消和执行槽位释放均等待实际保存；保存失败会明确报告，不自动重复工具操作。

## 子任务思考强度

- 创建子会话时同时传递该任务冻结的模型与思考强度，避免继承父会话旧强度。
- 已有任务按其自身冻结配置显示，不用当前机器人配置覆盖历史任务；执行模型原生支持的最高强度保留原值。

## 升级与验证范围

- 升级前备份完整数据根，Desktop、CLI/TUI 与 Gateway 同步升级；回退须恢复完整升级前备份。
- 源码验收覆盖真实模型派工、子任务读写及命令执行、复核交付、取消后继续对话。大日志和大对话分别测量；冷启动全量验证与旧同步存储兼容接口仍有成本。
- 产品截图由实施者自审，非独立审查。Windows/Linux 交互安装、完整读屏、任意项目的性能及长期日用不在本次断言内。
- 同步双语发布说明、README 版本入口和文档站更新日志。

## Release status

- **0.1.0-rc.17** fixes three performance hotspots during task execution and inconsistent reasoning effort in delegated conversations. Stable remains 0.0.18; this prerelease is for continued evaluation.

## Responsiveness during execution

- Reuse validated coordination state and read appended records instead of replaying the entire history for each progress read. Replacement, corruption and revision checks remain enforced.
- Keep historical-message and Bot-list avatars static. Animate only eligible current activity, reducing idle rendering work while respecting reduced-motion settings.
- Prepare large terminal conversation rewrites in a background worker. The main process performs a short version check and atomic commit. Completion, cancellation and execution-slot release wait for durable saving; a save failure is reported without automatically replaying tools.

## Delegated reasoning effort

- Pass both the frozen model and reasoning effort when creating a child conversation, avoiding inheritance of stale parent effort.
- Display existing tasks using their own frozen configuration, without replacing historical settings with the current Bot policy. Preserve native maximum effort where the execution model supports it.

## Upgrade and validation scope

- Back up the complete data root and upgrade Desktop, CLI/TUI and Gateway together. Rollback requires the complete pre-upgrade backup.
- Source acceptance includes actual model delegation, child file edits and commands, verification and delivery, cancellation and subsequent conversation. Large histories are measured separately; cold full validation and legacy synchronous storage APIs still have a cost.
- Product screenshots receive implementer self-review, not independent review. Interactive Windows/Linux installation, full screen-reader coverage, arbitrary-project performance and long-term daily use remain outside this claim.
- Synchronize bilingual release notes, README version links and the documentation-site changelog.
