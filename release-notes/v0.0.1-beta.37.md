## 新功能

- **用量统计面板**：新增每日用量热力与区间统计，可回填缺失模型单价，并在每次发送后持久化真实 provider 用量。
- **订阅配额展示**：模型设置可查看订阅配额；用量旁支持配额 tooltip，并优先展示上次配额后再静默刷新。
- **Search Chats**：跨工作区搜索与切换任务会话，输入时本地过滤更跟手。
- **新建任务快捷键**：支持可配置的 New Task 快捷键（默认 ⌘N）。
- **队列消息可编辑排序**：排队中的消息可编辑内容并调整顺序。
- **附件拖拽排序**：聊天附件支持拖拽重排。
- **Git 分支前缀默认 PeerAgent/**：新建任务分支时默认带 `PeerAgent/` 前缀。
- **Gemini Code Assist 项目/Base URL**：完善项目与 base URL 解析，订阅鉴权编辑时更稳定。

## 优化

- 冷启动更快，品牌入场更短；侧栏 logo 预加载。
- 上下文占用改为环形百分比，发送/流式过程中占用展示更稳定。
- 工作台顶栏高度收敛到 40px；侧栏与 Goal 列表统一为轻浮层表面。
- Quick Chat 随内容高度自适应窗口，唤醒更快；菜单对齐触发器，可见时才刷新并节流流式事件。
- 思考强度弹层按视口钳制，靠近边缘不再被裁切。
- 活跃会话操作区宽度收紧；硬删除仅保留在「已归档」列表（侧栏与设置页），活跃列表只保留归档。
- 多提供方压缩边界一致；流结束若尾随工具调用，最终正文仍可见。
- 模式命名改为 Agent，去掉危险色强调。

## 修复

- 修复 Google / OpenAI OAuth 经代理的 token 请求，以及设置页过期会话静默刷新。
- 修复 Gemini OAuth 展示与 curated 模型目录；编辑时保留订阅鉴权。
- 修复 Goal 计划在短暂流失败后状态恢复，以及 runner 流式消息持久化。
- 修复侧栏仅在首条消息后创建会话、决策上下文在交互卡等待时仍可见。
- 修复 Quick Chat 内容高度 IPC、紧凑菜单对齐，以及 TUI 共用 Desktop v2 模型目录。
- 修复 Search Chats 输入过滤仅本地生效，避免误触发远端。
