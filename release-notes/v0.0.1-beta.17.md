## 新功能

- **本地 MCP 连接支持 OAuth 2.0 授权**：连接本地 MCP 服务时支持标准 OAuth 2.0 授权码流程，接入需要登录的 MCP 服务更加顺畅。

## 优化

- 上下文用量估算更准确：计入工具 schema 的占用并修正中日韩字符的计数方式，用量进度条更贴近真实情况。
- 统一上下文用量为完整会话量口径，消除回合结束时进度条数值跳变的问题。

## 修复

- 修复读取含工具调用语法的文本后，模型可能把工具指令输出到正文并导致回合中断的问题；同时增加响应守卫兜底，自动纠偏。
- 修复历史压缩时未复用已解析的 provider 配置的问题。
- 修复模型下拉菜单被遮挡、裁剪的显示问题。

## What's New

- **Local MCP connections support OAuth 2.0**: standard authorization-code flow makes login-required MCP services smoother to connect.

## Improvements

- More accurate context usage estimates: tool schemas are counted and CJK character weighting is corrected.
- Context usage uses full-session accounting so the progress bar no longer jumps at turn end.

## Fixes

- Fixed cases where reading text with tool-call syntax could leak tool instructions into the body and break the turn; response guards auto-correct.
- History compaction now reuses the already-resolved provider config.
- Fixed model dropdown menus being clipped or covered.
