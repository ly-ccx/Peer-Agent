## 优化

- **上下文占用圆环**：主圆环改为显示实际发送给模型的上下文量，更符合「上下文占用」心智；自动压缩仍在后台按独立压力水位判定。
- **用量提示更干净**：圆环 hover 只保留「上下文」与缓存/额度信息，不再混入压缩压力文案。
- **过程块折叠偏好**：手动收起过程时间线后，流式更新中不会被自动展开重新打开。
- **侧栏状态更清晰**：区分进行中 / 已完成等状态；排队消息与 Goal 条目背景微调。

## 修复

- **OpenAI Responses 流挂起**：收到 `response.completed` / failed / `[DONE]` 后及时结束流，并增加空闲超时，避免 Grok 等模型把 `isStreaming` 卡死。
- **Goal Runner 不启动 / 递归启动**：intake 建 plan 后自动 kick runner；只在 goal-accepted 边沿启动，防止递归 auto-start；计划升级与 intake 流交接更稳。
- **切换会话丢队列**：跨会话切换时保留排队消息与草稿。
- **Workspace 黄点不灭**：无进行中任务时侧栏工作区黄点正确熄灭；路径末尾斜杠差异不再误判。
- **通知点击跳转**：系统通知点击可定位到对应源消息。
- **Responses 历史工具名**：回放时规范化带点号/空格的旧 function name，避免请求被拒。
- **TUI 恢复会话隔离**：按当前工作区过滤可恢复会话，并兼容旧 store。
- **模型选择器滚动跳动**：悬停上方模型不再强制滚回当前选中项。
- **过程时间线闪烁**：流式过程中时间线条目更稳定。

## CLI / npm

- 本版 GitHub Release 继续附带 CLI 归档（与 Desktop 同 tag）：`peer-darwin-arm64.tar.gz`。
- 可安装：`npm i -g @peer-agent/cli@beta`（需仓库已配置 `NPM_TOKEN`；否则仅发 GitHub Release，可从 Release 资产手动装 CLI）。
- 安装后执行 `peer --version` 应输出 `peer 0.0.1-beta.40`。
- 会话与设置仍落在 `~/.peer-agent`，与 Desktop 共享。
