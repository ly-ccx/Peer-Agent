## 新功能

- **会话列表常态展示相对时间**：左侧会话列表默认显示「几分钟前 / 昨天」等相对时间，更快定位最近会话。
- **Agent 调用内置浏览器自动切换视图**：当 Agent 使用内置浏览器工具时，工作台会自动展开并切到「浏览器」标签，操作过程实时可见。

## 优化

- 拖拽左栏分隔条时改用 rAF 合并写入，拖动更顺滑、卡顿明显减轻。
- 描述为空的技能不再被加载或借用，避免无效技能干扰技能列表。

## 修复

- 统一历史压缩的用量估算口径，进度条与触发阈值一致，达到阈值后会在回合结束时自动触发压缩。
- 修复 GPT 订阅上下文窗口被误设为 1M 的问题，改为 258K。
- 修复 OAuth 会话过期时仍可激活该 provider 的问题，并在过期时给出显性提示。
- 修复 OAuth 重新登录时端口被占用导致登录失败的问题。
- 登录成功后自动清除此前残留的错误提示。

## What's New

- **Relative timestamps in the session list** by default (“a few minutes ago / yesterday”) to find recent chats faster.
- **Agent browser tools auto-switch the view**: when the Agent uses the embedded browser, the workbench expands to the Browser tab so actions are visible live.

## Improvements

- Left rail resize uses rAF-coalesced writes for smoother dragging.
- Skills with empty descriptions are no longer loaded or borrowed.

## Fixes

- Unified history-compaction usage estimates so the progress bar matches the trigger threshold; auto-compact runs at turn end when over threshold.
- Fixed GPT subscription context window wrongly set to 1M; now 258K.
- Expired OAuth sessions can no longer activate that provider, with an explicit expired hint.
- Fixed OAuth re-login failures when the port was already in use.
- Successful login clears leftover error banners.
