## 说明

- **0.0.2-beta.4** 接入腾讯 SkillHub 全量技能市场，并补齐聊天本地图片预览、Kimi 多档推理力度与若干 Desktop 体验修复。
- SkillHub 以远程元数据同步 + 安装时验签下载为主：本地只做分页索引与展示，ZIP 在安装时按需下载并校验后进入现有 Skill Store。
- 本版不改变本地能力执行、显式授权与 Evidence 边界。

## 新功能

- **SkillHub 全量市场**：同步 SkillHub 元数据到本地索引，支持分页、搜索、分类筛选、排序与后台断点续传；同步失败时继续使用最近完整快照。
- **验签安装**：安装时按 namespace/slug/version 下载 ZIP，校验 SkillHub Ed25519 平台签名、ZIP MD5 与 hash v1 内容指纹，以及 ZIP 安全边界，通过后写入 Skill Store。
- **安装作用域**：详情中可选择安装到全局（`userData/skills`）或当前工作区（`workspace/skills`）；无工作区时禁用工作区选项。
- **技能卸载**：已安装用户级 Skill 支持卸载；项目级 workspace Skill 不会从这里误删源文件。
- **聊天本地图预览**：会话附件中的本地图片可在聊天界面直接预览，不再只显示路径或占位。

## 优化

- 市场详情统计改为纯展示，安装位置与安装按钮分层更清晰；去掉多余圆角套层。
- Skill 图标优先展示 SkillHub `iconUrl`，失败时回退字母头像。
- 分类筛选改用通用 Dropdown，与 Desktop 其他控件一致。
- Kimi Coding Plan / Moonshot 对齐官方 off/low/high/max 推理力度，并修正力度滑条几何对齐。
- Automation 详情标题与状态、元数据层级更清晰。
- 应用从后台激活时检查更新。

## 修复

- 卸载 Skill 后详情弹窗走统一退场动画，不再瞬间消失。
- 市场卡片底部标签与安装按钮在等高布局下置底对齐。

## CLI（仅命令行）

- 本版 GitHub Release 附带 CLI 归档（与 Desktop 同 tag / 同版本）。
- 资产示例：`peer-darwin-arm64.tar.gz`（内含 `peer` + `peer-credential-helper`，**必须同目录**）。
- 安装方式：
  - **npm（有 `NPM_TOKEN` 且 publish 成功时）**：`npm i -g @peer-agent/cli@beta`（或 `pnpm add -g @peer-agent/cli@beta`），`postinstall` 自动拉本版归档。
  - **手动**：解压归档后将目录加入 `PATH`，执行 `peer --version` 校验，再运行 `peer`。
- 可不装 Desktop；会话与设置仍落在 `~/.peer-agent`，与客户端共享。

## Notes

- **0.0.2-beta.4** brings the full Tencent SkillHub skill marketplace, local chat image previews, multi-level Kimi reasoning effort, and several Desktop polish fixes.
- SkillHub works as remote metadata sync plus install-time verified download: the app keeps a local paginated index for browsing, and only downloads ZIPs when installing after signature and integrity checks into the existing Skill Store.
- Local capability execution, explicit authorization, and Evidence remain unchanged.

## What's New

- **Full SkillHub marketplace**: sync SkillHub metadata into a local index with pagination, search, category filters, sorting, and background resume from checkpoints; keep the last complete snapshot when a refresh fails.
- **Verified install**: download the ZIP for a bound namespace/slug/version, verify SkillHub Ed25519 platform signatures, ZIP MD5, hash v1 content fingerprint, and archive safety bounds before entering the Skill Store.
- **Install scope**: choose global (`userData/skills`) or current workspace (`workspace/skills`) in the detail panel; workspace install is disabled when no workspace is open.
- **Skill uninstall**: user-installed skills can be removed; project-level workspace skills are not deleted from this path.
- **Local chat image previews**: local attachment images render inline in chat instead of only showing a path or placeholder.

## Improvements

- Marketplace detail stats are display-only, with a clearer install-location + install-button action area and fewer nested rounded cards.
- Skill icons prefer SkillHub `iconUrl`, falling back to letter avatars on failure.
- Category filtering uses the shared Dropdown control for consistent Desktop chrome.
- Kimi Coding Plan / Moonshot map to official off/low/high/max effort, with corrected effort-slider geometry.
- Automation detail headers separate title from status and metadata more clearly.
- The app checks for updates when reactivated from the background.

## Fixes

- Uninstalling a skill closes the detail overlay with the shared exit animation instead of disappearing instantly.
- Marketplace card footers stay bottom-aligned in equal-height grid cards.

## CLI (command-line only)

- This GitHub Release also ships CLI archives (same tag / version as Desktop).
- Asset example: `peer-darwin-arm64.tar.gz` (contains `peer` + `peer-credential-helper`; **must stay side-by-side**).
- Install:
  - **npm (when `NPM_TOKEN` is present and publish succeeds)**: `npm i -g @peer-agent/cli@beta` (or `pnpm add -g @peer-agent/cli@beta`); `postinstall` fetches this version's archive.
  - **Manual**: extract the archive, add the directory to `PATH`, run `peer --version`, then `peer`.
- Desktop is optional; sessions and settings still live under `~/.peer-agent` and are shared with the client.
