## 说明

- **Peer Agent 0.1.0-beta.2** 是 0.1.0 的第二版预发布，走 beta 更新通道。正式版仍是 **0.0.18**。
- 项目代理需在 设置 → 开发者 打开。开关关闭时，界面仍是原来的会话。
- 更新日志页面可以在「正式版」和「预发布」之间切换。预发布条目会标成「预发布」。

## 新功能

- 打开开关后，主界面换成机器人列表。每个项目对应一个机器人。
- 可以和机器人对话，看到你的话、它的回复，以及需要你处理的卡片。
- 档案里可以看概况、任务和设置。点来源可以打开这项任务的现场。
- 可以绑定一个已有文件夹，或新建一个受管机器人。新建或绑定之后，它会用只读方式熟悉这个项目。
- 机器人可以开出任务。任务按开任务时选定的模型推进。机器人自己不能写文件。
- 任务做完后按签收策略处理：可以自动签收，也可以等你确认。
- 机器人可以记住这个项目里的事实，也可以按你的要求撤回一条记忆。
- 需要你时，系统通知和菜单栏角标会告诉你。通知跟着送达策略走。

## 已知限制

- 不打开开发者开关，就看不到机器人列表。
- 项目目标、多任务并行、今日小结、远程查看，以及终端里的机器人，这一版都还没有开放。
- 档案里的记忆列表只能查看。签收策略和每个项目单独的模型选择也只显示，这一版不能在档案里修改。
- 主动性目前按「标准」档计算。

## 降级说明

- 可以重新安装 0.1.0-beta.1 或 0.0.18，原来的会话可以打开。开关关闭时，这一版不改写会话正文。
- 打开过机器人之后，档案和记忆写在本机数据目录。旧版会忽略这些新增文件。

## CLI（仅命令行）

- CLI 与 Desktop 共用 0.1.0-beta.2。终端里的 `peer` 仍是现在的会话 Agent，还不会打开项目机器人。
- 压缩包矩阵仍是 macOS ARM64 与 Linux x64。请把 `peer` 和 `peer-credential-helper` 放在同一目录。

## Notes

- **Peer Agent 0.1.0-beta.2** is the second prerelease on the 0.1.0 line and uses the beta update channel. The stable release remains **0.0.18**.
- The project agent must be turned on in Settings → Developer. While that switch is off, the app stays on the current conversation screen.
- The changelog page can switch between Stable and Pre-release. Pre-release entries are marked Pre-release.

## What's New

- With the switch on, the main screen becomes a bot list. Each project has one bot.
- You can talk with a bot and see your messages, its replies, and cards that need you.
- The profile shows an overview, tasks, and settings. A source link opens that task's scene.
- You can bind an existing folder or create a managed bot. After that, the bot familiarizes itself with the project using read-only tools.
- A bot can open a task. The task runs with the model chosen when it was opened. The bot itself cannot write files.
- A finished task follows the acceptance policy: it can be accepted automatically, or it can wait for you.
- A bot can remember a fact about the project, and it can withdraw a memory when you ask.
- When the bot needs you, a system notification and the menu-bar badge say so. Notifications follow the surfacing policy.

## Known limits

- The bot list stays hidden until the developer switch is on.
- Project objectives, parallel tasks, the daily digest, remote viewing, and a bot in the terminal are not in this prerelease.
- The memory list in the profile is view-only. Acceptance policy and a per-project model choice are shown and cannot be edited there yet.
- Proactivity is calculated at the standard level.

## Downgrade

- You can install 0.1.0-beta.1 or 0.0.18 again and open your existing conversations. With the switch off, this prerelease does not rewrite conversation text.
- After a bot has been opened, its profile and memories live in the local data directory. Older versions ignore those added files.

## CLI (command-line only)

- The CLI shares version 0.1.0-beta.2 with Desktop. `peer` in the terminal is still the current conversation agent and does not open a project bot.
- The archive matrix remains macOS ARM64 and Linux x64. Keep `peer` and `peer-credential-helper` in the same directory.
