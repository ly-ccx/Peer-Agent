## 新功能

- **ChatGPT 订阅模型目录展开为多条可选模型**：订阅记录不再只绑定一个当前模型，聊天菜单二级即可列出该订阅下的全部模型，并支持会话级独立切换；空目录时优雅降级。

## 优化

- **升级体系 UI 改进**：有新版本时显示「新版本」文字 Tag（替代原红点），更直观；下载中环形进度旁显示百分比文字；下载完成后版本号旁持久挂「安装」按钮，设置页升级面板也提供一致的安装入口。

## 修复

- 修复极致模型（Qoder Ultimate）在多轮工具调用时报错 `unexpected tool_use_id found in tool_result blocks`：发送前合并相邻的 assistant 消息，且带工具调用的 assistant 不再发送空内容，保证工具消息正确配对。
- 修复更新下载完成卡片右上角 ✕ 关闭按钮与安装按钮重叠的问题。

## What's New

- **ChatGPT subscription catalogs expand to many models**: A subscription is no longer locked to one current model; the chat menu can list every model under that subscription with per-session switching, and degrades gracefully when the catalog is empty.

## Improvements

- **Update UI polish**: Available updates show a “New version” text tag instead of a red dot; download ring shows percent text; after download an Install action stays next to the version, with a matching install entry in Settings.

## Fixes

- Fixed Qoder Ultimate multi-tool-call error `unexpected tool_use_id found in tool_result blocks` by merging adjacent assistant messages before send and not sending empty assistant content when tool calls are present.
- Fixed the finished-download card’s close (✕) button overlapping the Install button.
