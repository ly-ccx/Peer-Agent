## 说明

- **Peer Agent 0.0.4-beta.4** 把后续 Goal 收成一条 Goal Thread，工作台只保留一张卡片。
- 设置里可直接添加 OpenRouter，官方 API 作为一等通道接入。
- 工作台讨论与待处理结果不再被截断，刷新风暴也压住了。
- 文档站 Changelog 已同步本版说明。

## 新功能

- **Goal Thread**：后续验收卡并入同一条线程；模型漏传 `parentPlanId` 时，也会挂到最近完成的计划上。
- **一张卡片**：工作台结果区按线程只显示一张卡，外壳绑到最新待处理轮次，并内嵌精简的父子树。
- **OpenRouter**：设置可添加官方 OpenRouter API，预填 Base URL 与 API Key，作为第三方 OpenAI Chat 通道。

## 优化

- **工作台讨论**：首页讨论区即使没有未读也会保留，待处理结果全部展示，不再只预览四张卡。
- **刷新节流**：合并 `taskOverview:changed` 广播，隐藏窗口时跳过重载，托盘重建降频，未变计划索引走缓存。
- **产品叙事**：README 与文档站统一到「完全开源 + 任务流」表述，能力分组与架构分层说明一并更新。

## 修复

- 统一 SkillHub 工具栏控件圆角。
- 品牌图标回退到开天空猫原画，不再使用铺满画幅的日夜插画。

## CLI（仅命令行）

- 本版 GitHub Release 附带 CLI 归档（与 Desktop 同 tag / 同版本）。
- 可通过 `npm i -g @peer-agent/cli@beta`（或 `pnpm add -g @peer-agent/cli@beta`）安装 beta 通道版本；`postinstall` 会拉取本版归档。
- 也可手动解压归档，将目录加入 `PATH`，执行 `peer --version` 校验后运行 `peer`。
- CLI 与 Desktop 继续共享 `~/.peer-agent` 下的会话和设置。

## Overview

- **Peer Agent 0.0.4-beta.4** collapses follow-up Goals into one Goal Thread, so the workbench keeps a single card.
- Settings can add OpenRouter directly as a first-class official API channel.
- Workbench discussions and pending results stay visible, and refresh storms are throttled.
- The docs changelog is in sync with this release.

## What's New

- **Goal Thread**: related acceptance cards share one thread; later follow-ups attach to the last completed plan when the model omits `parentPlanId`.
- **One card**: the result grid shows one card per thread. The shell binds to the latest pending round and embeds a compact parent/child tree.
- **OpenRouter**: add the official OpenRouter API from settings, with a prefilled base URL and API key, as a third-party OpenAI Chat channel.

## Improvements

- **Workbench discussions**: the home discussion section stays even when nothing is unread, and the full result-ready queue is shown instead of a four-card preview.
- **Refresh throttle**: merge `taskOverview:changed` broadcasts, skip hidden reloads, back off tray rebuilds, and cache unchanged plan indexes.
- **Product narrative**: README and the docs site now lead with fully open source plus task flow, with updated capability grouping and architecture layers.

## Fixes

- Unify SkillHub toolbar control radius.
- Restore the open-sky cat brand icons instead of the full-bleed day and night illustrations.

## CLI (command-line only)

- This GitHub Release ships CLI archives under the same tag and version as Desktop.
- Install the beta channel with `npm i -g @peer-agent/cli@beta` (or `pnpm add -g @peer-agent/cli@beta`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
