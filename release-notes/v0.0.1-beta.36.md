## 新功能

- **纯字标启动页**：启动过渡改为主题自适应字标与黄支撑线，去掉流式泼墨/水墨 canvas，暗色浅字、浅色深墨，入场更干净。
- **macOS 毛玻璃 Chrome**：主窗口启用 vibrancy，侧栏与 Workbench 外壳使用半透明玻璃材质；正文主面保持实色对比度，并支持减少透明度偏好回退。
- **模型选项与渠道元数据**：支持提供方模型选项，刷新已保存模型元数据，并改善 Grok 渠道与目录信息展示。
- **Quick Chat 任务工作区标识**：快捷对话可识别并区分任务工作区，便于多任务并行。

## 优化

- 聊天热更新隔离、滚动与输入卡顿降低，跨设置页时保持聊天挂载。
- 自动上下文压缩触发与用量展示对齐，预检路径更稳定。
- 设置导航分组整理，聊天顶栏高度收敛到 36px。
- Goal 面板减少跨会话无效刷新；Explorer / Verifier 侧流改为 ephemeral，内部 JSON 不再写入聊天消息。

## 修复

- 修复提供方 reasoning 默认值与 effort map 未正确尊重的问题。
- 修复 Grok OAuth 连通性与渠道列表展示异常。
- 修复 Qoder 能力元数据被覆盖丢失的问题。
- 移除 token 用量旁「计费待接入」类占位文案。

## What's New

- **Wordmark-only splash**: Launch transition uses a theme-aware wordmark and yellow support line; removes stream ink/canvas effects. Dark mode uses light glyphs, light mode uses deep ink for a cleaner entry.
- **macOS frosted Chrome**: Main window vibrancy with translucent glass on the sidebar and Workbench shell; the main content surface stays solid for contrast, with reduced-transparency fallback.
- **Model options & channel metadata**: Provider model options, refresh of saved model metadata, and better Grok channel/catalog display.
- **Quick Chat task workspace labels**: Quick Chat can identify and distinguish task workspaces for parallel work.

## Improvements

- Chat HMR isolation, less scroll/input jank; chat stays mounted across settings pages.
- Auto-compact triggers align with usage display; preflight path is more stable.
- Settings nav regrouped; chat top bar height converges to 36px.
- Goal panel avoids useless cross-session refresh; Explorer / Verifier side streams are ephemeral so internal JSON is not written into chat messages.

## Fixes

- Respect provider reasoning defaults and effort maps correctly.
- Fixed Grok OAuth connectivity and channel list display issues.
- Fixed Qoder capability metadata being overwritten/lost.
- Removed “billing not wired” style placeholder copy next to token usage.
