## 新功能

- **CLI 技能与 MCP 管理**：新增 `peer skill` / `peer mcp` 管理命令，支持连接技能与 MCP 能力，并提供中英文界面。
- **TUI Goal 状态面板**：TUI 新增 Goal 状态面板，可查看目标执行进度。
- **TUI 交互问答**：`request_user_input` 已接入 TUI，Agent 提问可以直接在终端里回答。
- **TUI 品牌动画**：B3Wordmark 启动动画（逐行显现 + 信号呼吸）。

## 优化

- **侧栏更干净**：移除工作区头部的橙色「其它工作区运行中」提示点——它太容易被误读为当前工作区状态；下拉列表内的绿色运行点保留，作为运行状态的单一来源。
- **压缩交接展示对齐**：TUI 的 compact handoff 呈现与 Desktop 对齐。

## 修复

- **Qoder 上下文窗口口径统一**：provider 配置窗口改为按 contextTier 档位投影后的可用输入窗口（如 1M 档 − 输出预留 = 980k），与实际发送链路同口径。修复切换模型后上下文圆环分母回退到过期值（328.8k/180k 显示 100%）以及压缩预检按错误窗口误判的问题。
- **TUI 跟随 macOS 浅色外观**：浅色模式下不再误用深色配色；输入区文字在浅色表面保持可读。
- **Goal Runner 交接串行化**：Desktop Goal Runner 交接不再并发错乱。
- **通知路由**：通知正确路由到会话所属工作区。
- **「加载更多」残留**：会话列表不再显示过期的加载更多按钮。
- **交互工具调用类型**：runtime-node 正确解析 interaction tool call 类型。
- **Provider 连接恢复**：连接异常后的恢复流程更稳。
- **工作台预览**：隐藏非活跃 workbench 预览，减少资源占用。
- **更新图标**：有可用更新时正确显示图标。
- **压缩摘要保留**：最近决策中的压缩摘要不再丢失。

## CLI / npm

- 本版 GitHub Release 继续附带 CLI 归档（与 Desktop 同 tag）：`peer-darwin-arm64.tar.gz`。
- 可安装：`npm i -g @peer-agent/cli@beta`。
- 安装后执行 `peer --version` 应输出 `peer 0.0.1-beta.41`。
- 会话与设置仍落在 `~/.peer-agent`，与 Desktop 共享。

## What's New

- **CLI skill & MCP management**: New `peer skill` / `peer mcp` commands to connect skills and MCP capabilities, with Chinese/English UI.
- **TUI Goal status panel**: View goal execution progress in the TUI.
- **TUI interactive Q&A**: `request_user_input` is wired into the TUI so you can answer Agent questions in the terminal.
- **TUI brand animation**: B3Wordmark launch animation (line-by-line reveal + signal breath).

## Improvements

- **Cleaner sidebar**: Removed the orange “other workspaces running” header dot—too easy to misread as current-workspace status; green running dots inside the dropdown remain as the single source of truth.
- **Compact handoff display**: TUI compact handoff presentation aligns with Desktop.

## Fixes

- **Unified Qoder context-window accounting**: Provider config window uses the usable input window projected from contextTier (e.g. 1M tier − output reserve = 980k), same as the send path. Fixes the context ring denominator falling back to a stale value after model switch (328.8k/180k showing 100%) and compact preflight using the wrong window.
- **TUI follows macOS light appearance**: Light mode no longer wrongly uses dark colors; input text stays readable on light surfaces.
- **Goal Runner handoff serialization**: Desktop Goal Runner handoff no longer races concurrently.
- **Notification routing**: Notifications route to the workspace that owns the session.
- **Stale “load more”**: Session list no longer shows an outdated load-more button.
- **Interaction tool-call types**: runtime-node correctly parses interaction tool-call types.
- **Provider reconnect**: Recovery after connection errors is more solid.
- **Workbench preview**: Hide inactive workbench previews to save resources.
- **Update icon**: Shows correctly when an update is available.
