## 说明

- **Peer Agent 0.0.5-beta.1** 是 `0.0.4` 之后的第一颗开发线 beta：Goal Thread 进全局工作台，结果抽屉直接复用当前对话。
- 任务概览可折叠查看主要产物，代码 diff 和图片支持 hover 预览。
- 思考过程改成单行实时滚动，首次启动直接进入聊天。
- 文档站 Changelog 已同步本版说明。

## 新功能

- **全局工作台 Goal Thread**：待验收结果按线程分组，父子轮次拍成同级列表，一张卡看完整条线。
- **结果抽屉**：复用当前对话界面，可最大化；同一线程上的待验收项可一次全部接受。
- **主要产物**：任务概览汇总代码、图片和文件变更，hover 可看 diff 或缩略图。
- **实时思考条**：模型思考时只占一行，尾部跟着最新内容滚动。
- **工作台能力入口**：从工作台顶栏打开当前工作区的能力面板。
- **@ 提文件**：输入框用 `@` 点选工作区文件，不再误报附件错误。
- **首次启动**：没有会话时直接进入聊天，不再先停在空首页。

## 优化

- 结果页复用对话回合渲染，图片和 HTML 可预览，大图不再被裁小。
- 工作台卡片按最短列排布，字符图标换成线性 SVG。
- 无模型通道的空首页不再露出输入框。
- 接受结果卡后，列表回填更顺，卡片底角不再被裁切。

## 修复

- 聊天里的 Markdown 图片语法能正常显示。
- 自指父节点的 Goal Thread 不再拆成两张卡。
- `@` 选择器行可点，文件夹可置顶，会话 id 周围的高亮不再丢。
- 后台任务也能调度对话内嵌浏览器。
- 发版门禁改用真实 `generatedAt`，避免站点 changelog 时间戳漂移。

## CLI（仅命令行）

- 本版 GitHub Release 附带 CLI 归档（与 Desktop 同 tag / 同版本）。
- 可通过 `npm i -g @peer-agent/cli@beta`（或 `pnpm add -g @peer-agent/cli@beta`）安装 beta 通道版本；`postinstall` 会拉取本版归档。
- 也可手动解压归档，将目录加入 `PATH`，执行 `peer --version` 校验后运行 `peer`。
- CLI 与 Desktop 继续共享 `~/.peer-agent` 下的会话和设置。

## Overview

- **Peer Agent 0.0.5-beta.1** is the first beta on the `0.0.5` line after `0.0.4`: Goal Threads land on the global workbench, and the result drawer reuses the live chat surface.
- Task overview folds primary artifacts, with hover previews for code diffs and images.
- Thinking is a single-line live ticker, and first-run opens directly in chat.
- The docs changelog is in sync with this release.

## What's New

- **Goal Threads on the global workbench**: pending acceptances group by thread, flatten parent/child rounds into a sibling list, and keep one card for the whole line.
- **Result drawer**: reuses the live chat surface, can maximize, and can accept every pending item on a thread at once.
- **Primary artifacts**: task overview summarizes code, image, and file changes; hover to preview a diff or thumbnail.
- **Live thinking bar**: model thinking stays on one line and follows the latest tail.
- **Workbench capabilities**: open the current workspace's capability panel from the workbench header.
- **@ files**: mention workspace files from the composer without false attachment errors.
- **First-run**: new installs land in chat instead of an empty home screen.

## Improvements

- Result view reuses chat turn rendering, previews images and HTML, and no longer shrinks large images.
- Workbench cards pack by the shortest column, and character icons become linear SVGs.
- The empty home hides the composer when no provider is configured.
- Accepting a result card refills the list more smoothly, without clipping card corners.

## Fixes

- Render Markdown image syntax in chat.
- Keep self-parent Goal Threads on one card.
- Make `@` picker rows clickable, pin folders, and keep highlight around session ids.
- Let background tasks schedule the in-conversation browser.
- Stamp changelog `generatedAt` with a real time so the docs site no longer drifts.

## CLI (command-line only)

- This GitHub Release ships CLI archives under the same tag and version as Desktop.
- Install the beta channel with `npm i -g @peer-agent/cli@beta` (or `pnpm add -g @peer-agent/cli@beta`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
