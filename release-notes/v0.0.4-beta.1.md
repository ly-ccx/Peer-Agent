## 说明

- **Peer Agent 0.0.4-beta.1** 聚焦多任务并行时的工作台可见性、任务续接准确性与 Desktop 交互流畅度。
- 即使多个后台任务持续推进，当前会话的滚动、输入和侧边栏浏览也能保持响应。

## 新功能

- **运行状态提示**：侧边栏工作区会标记正在执行任务的位置，无需逐个打开会话确认后台进度。

## 优化

- **多任务性能**：任务总览按当前会话或工作区的索引范围查询，避免未打开的历史任务反复触发大规模计划读取。
- **流畅滚动与输入**：合并滚动帧中的当前位置探测，暂停被抽屉覆盖页面的后台刷新，并复用未变化的任务投影，减少主线程占用。
- **任务续接边界**：将继续既有任务与提交新的用户输入分开处理，降低恢复或切换任务时的状态歧义。

## 修复

- 修复多个任务执行时打开会话抽屉、上下滚动或输入内容出现明显卡顿的问题。
- 修复未打开任务的高频进度事件仍让当前页面执行昂贵全局查询的问题。
- 修复任务续接动作可能被当作新用户输入处理的问题。

## CLI（仅命令行）

- 本版 GitHub Release 附带 CLI 归档（与 Desktop 同 tag / 同版本）。
- 可通过 `npm i -g @peer-agent/cli@beta`（或 `pnpm add -g @peer-agent/cli@beta`）安装 beta 通道版本；`postinstall` 会拉取本版归档。
- 也可手动解压归档，将目录加入 `PATH`，执行 `peer --version` 校验后运行 `peer`。
- CLI 与 Desktop 继续共享 `~/.peer-agent` 下的会话和设置。

## Overview

- **Peer Agent 0.0.4-beta.1** focuses on workbench visibility, accurate task continuation, and responsive Desktop interactions while multiple tasks run in parallel.
- Scrolling, typing, and browsing the sidebar remain responsive even when background tasks continue to make progress.

## What's New

- **Running-work indicator**: sidebar workspaces now show where tasks are actively running, so background progress is visible without opening every conversation.

## Improvements

- **Parallel-task performance**: task overviews now query indexed conversation or workspace scopes instead of repeatedly hydrating large sets of unopened historical plans.
- **Responsive scrolling and typing**: current-position detection is coalesced per animation frame, covered pages pause background refreshes, and unchanged task projections retain stable references to reduce main-thread work.
- **Clear task-continuation boundary**: continuing an existing task is handled separately from submitting new user input, reducing ambiguity during recovery and task switching.

## Fixes

- Fix severe lag when opening the conversation drawer, scrolling, or typing while several tasks are running.
- Fix high-frequency progress events from unopened tasks triggering expensive global queries in the active page.
- Fix task-continuation actions being handled as new user input in some flows.

## CLI (command-line only)

- This GitHub Release ships CLI archives under the same tag and version as Desktop.
- Install the beta channel with `npm i -g @peer-agent/cli@beta` (or `pnpm add -g @peer-agent/cli@beta`); `postinstall` downloads this release's archive.
- Alternatively, unpack an archive manually, add its directory to `PATH`, run `peer --version`, and then run `peer`.
- CLI and Desktop continue to share sessions and settings under `~/.peer-agent`.
