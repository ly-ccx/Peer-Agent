## 说明

- **Peer Agent 0.0.17** 修复 OpenCode Go 的思考强度，并修正桌面固定栏与任务监控浮层的显示。

## 修复

- OpenCode Go 按每个模型自己声明的思考档位发送请求。没有声明档位的模型（包括 MiMo-V2.6-Flash）不再附带全局「极高」档，避免对话返回 400。
- 对齐桌面固定栏，并恢复任务监控浮层的磨砂效果。

## CLI（仅命令行）

- CLI 与 Desktop 共用 0.0.17 版本号。本版 CLI 压缩包矩阵为 macOS ARM64、Linux x64；不提供 Windows CLI 压缩包，最终以 Release 资源为准。
- 请将压缩包中的 `peer` 与 `peer-credential-helper` 保存在同一目录。Desktop 提供 macOS、Windows 和 Linux 安装包。

locale:en-US

## Notes

- **Peer Agent 0.0.17** fixes OpenCode Go reasoning levels and restores the desktop pinned bar and task-monitor overlay.

## Fixes

- OpenCode Go now sends only the reasoning levels declared for each model. Models without declared levels, including MiMo-V2.6-Flash, no longer receive the global “xhigh” setting, which avoids the HTTP 400 chat failure.
- Align the desktop pinned bar and restore the frosted task-monitor overlay.

## CLI (command-line only)

- CLI and Desktop share version 0.0.17. CLI archives target macOS ARM64 and Linux x64; no Windows CLI archive is provided. Consult the actual Release assets for availability.
- Keep `peer` and `peer-credential-helper` in the same directory. Desktop installers are provided for macOS, Windows, and Linux.
