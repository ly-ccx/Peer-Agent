## 新功能

- **Goal 自动执行绑定工作区**：Goal 自动推进时会锁定到目标代码仓工作区执行，跨仓库场景下操作落点更准确，并新增运行轨迹追踪，Goal 面板能看到每一步的执行来源。
- **App UI 语义 Token 层**：新增 `--ui-*` 语义 token，聊天界面样式统一迁移到该 token 体系，主题一致性和后续换肤维护更省心。

## 优化

- **添加/编辑模型改为弹窗**：设置里添加和编辑模型供应商都改用居中 Overlay 弹窗，不再挤在列表底部，多个供应商时定位更清晰。
- **任务拆解措辞更像人话**：Goal 任务拆解生成的子任务标题减少术语堆砌和编号塞信息，改为一句话讲清"这步做什么"，降低阅读负担。

## 修复

- **修复取消请求跨域鉴权 401**：聊天取消（cancel）改走同域网关，不再裸 fetch 跨域直连，修复跨域场景下的鉴权失败。
- **修复思考态动画**：去掉"思考中"激活态多余的三点，并修顺 shimmer 光扫效果。
