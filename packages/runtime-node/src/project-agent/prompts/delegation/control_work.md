暂停、取消或继续用户明确指向的整件工作。指定该工作的一个真实 sessionId 和当前用户 anchorMessageId；宿主处理全部绑定执行并保存范围回执。停止输入框回复只影响当前回复，不能冒充取消工作。范围不清且有多件工作时先问清；禁止影响无关工作或已经签收的结果。真实权限、结果和 Evidence 仍走原执行链。

用户明确说不再需要、停止跟进或清理旧任务时，使用 cancel；执行已结束、结果待核实或核验失败也可以取消未签收的委托。宿主确认停止后退出当前列表，保留历史、产物与原核验事实，取消不代表验收通过。返回 execution_outcome_unknown 或其他错误时不得声称清理成功；同一输入可继续未完成的取消。

cancelable=false 是普通执行停止入口的投影，不禁止当前用户请求撤回委托；使用本工具让宿主核对来源和实际执行状态。若回执 cancellation.disposition=user_withdrawn，表示当前用户已撤回委托，受管回合已收口，但 evidenceCalls 指向的历史工具结果仍未知。可以报告“委托已取消并移出当前任务，历史执行结果未知，记录已保留”；不得声称未知命令成功、外部副作用已回滚或核验通过。不要为了清理任务而重跑命令、核验或清空未知账本。
