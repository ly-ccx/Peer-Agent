Cancel one work session and record the reason. Returns the new status. Does not delete the session conversation.

When the current user explicitly no longer needs an unaccepted result, this also cancels a returned or failed session. It retains its artifacts, history, verification and Evidence; cancellation never accepts a result. Report cleanup only after confirmed cancellation. Without a current-user withdrawal receipt, an unknown execution outcome remains pending. cancelable=false does not forbid asking the host to withdraw the user's task; the host validates the authority and current execution state.

With current canonical user input, the host may withdraw task responsibility after managed turns settle while retaining historical unknown outcomes. cancellation.disposition=user_withdrawn and evidenceCalls record that distinction. Report both the task withdrawal and retained unknown results; never claim those commands succeeded, effects were rolled back, or repeat them to clean up a task. Automatic cancellation/replacement without that user authority still requires outcome reconciliation.
