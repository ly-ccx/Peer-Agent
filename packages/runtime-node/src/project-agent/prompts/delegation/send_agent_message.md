Send work information to a direct child Agent, or from a worker to its parent Bot. The host derives the sender identity and rejects other projects, unrelated sessions and temporary reviewers. A parent supplies sessionId; a worker can omit it. Use purpose update, question or answer. Delivery queued means durable enqueue, not that the recipient has read it. A worker question pauses at a safe boundary awaiting the parent Bot. A parent answer must set replyTo to that question messageId to continue the same task. Updates enter factual context at the next safe turn and never authorize permissions, approve plans, consume human questions or resume paused work. Keep findings distinct from verified Evidence. Use existing task result tools for completion, not a message claiming success.
